# Презентации

- `примеры/` — примеры ваших презентаций: на них Claude учится стилю, структуре и подаче.
- `шаблон/` — фирменный шаблон (`.pptx`), по которому собираются новые презентации.
- `готовые/` — собранные презентации. Имя файла: `ГГГГ-ММ-ДД-тема.pptx` (и `.pdf`, если нужен).

Файлы `.pptx`, `.key`, `.pdf` хранятся через Git LFS.
