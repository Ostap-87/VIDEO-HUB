# Презентации

- `примеры/` — присланные примеры (`ИИ.pdf`, `Alibaba Campus Education.pdf`): по ним сделан шаблон.
- `шаблон/` — фирменный шаблон Global Tech Tour (HTML/CSS → PDF), повторяет дизайн примеров 1:1.
- `контент/` — содержание презентаций в JSON (один файл = одна презентация).
- `готовые/` — собранные презентации `ГГГГ-ММ-ДД-тема.pdf` и `превью/` (каждый слайд PNG + лист-обзор JPG).

Файлы `.pptx`, `.key`, `.pdf` хранятся через Git LFS.

## Новая презентация за несколько минут

1. Скопируйте `контент/2026-10-08-тайланд.json` в `контент/ГГГГ-ММ-ДД-тема.json` и замените текст.
2. Логотипы компаний — из `source-videos/логотипы/<отрасль>/` (PNG с прозрачным или белым фоном, SVG).
   Нет логотипа — не указывайте `logo`, будет текстовый логотип с названием.
3. Соберите:

   ```bash
   python3 презентации/шаблон/build.py презентации/контент/ГГГГ-ММ-ДД-тема.json
   ```

   Получится `готовые/ГГГГ-ММ-ДД-тема.pdf`, `готовые/превью/ГГГГ-ММ-ДД-тема/NN.png` и `готовые/превью/ГГГГ-ММ-ДД-тема.jpg`.
4. Посмотрите лист-обзор, поправьте JSON, пересоберите. Быстрая проверка одного слайда: `--only 5 --no-pdf`.

Нужны Python 3 с `jinja2` и `Pillow`, Node.js и Playwright с Chromium (в облачной среде уже стоят:
`PLAYWRIGHT_BROWSERS_PATH=/opt/pw-browsers`). Ключи: `--only 1,5,7`, `--no-pdf`, `--html` (сохранить HTML рядом),
`--keep` (оставить PNG 1920×1080), `--outdir`.

## Экспедиция с сайта → презентация одной командой (конвертер)

```bash
python3 презентации/шаблон/from_site.py thailand-food-dairy-expedition --build
python3 презентации/шаблон/from_site.py --list th          # все экспедиции страны (th, jp, vn, id, in, my, ae, kr, cn)
```

`from_site.py` скачивает JS-бандл сайта (`https://globaltechtour.ru/` → `/assets/index-*.js`; ключ `--bundle путь` — взять
сохранённый), берёт данные экспедиции и карточки её компаний и пишет `контент/<дата>-<страна>-<тема>.json`
(`--out` — другое имя), с `--build` сразу собирает PDF и превью. Около 20–40 секунд на презентацию.

Порядок слайдов как в ручной «Тайланд»: обложка → «Почему мы» → «Программа» (блоки дней) → «Маршрут» (если городов
больше одного) → «Программа по дням» → карточка каждой компании → «Выгоды» → «Формат и условия» → «Контакты».
Робот на фоне — по стране (`th` → `bangkok` и т. д.). «О рынке» и «Как проходит» не делаются: на сайте нет таких данных.

Откуда тексты (только данные сайта, ничего не придумывается):
- цифры карточки компании — из её описания на сайте дословно: «15 430 магазинов», «~70% рынка», «$265 млн
  привлечено», «№2 в мире по числу магазинов», год основания, бренды и платформы («Typhoon — языковая модель»),
  партнёры, группа; не хватает — «площадка визита» (город) и «День N»;
- «Почему выбран» — главная мысль описания (лидерство, «X — крупнейший …», что компания делает);
  «Фокус визита» (вместо «Чему учимся») — другое предложение описания про технологии/продукты;
- тайское (японское, китайское) название — поле `name_zh` карточки, только если оно есть;
- даты, стоимость — с сайта; нет — «По запросу».
Склонения («в 135 магазинах» → «135+ магазинов») — `pymorphy3` (`pip install pymorphy3 pymorphy3-dicts-ru`).

Логотипы: сначала ищется в библиотеке (`reels-studio/library/brands.json`, поле `site_logo` — ссылка сайта),
нет — скачивается с `globaltechtour.ru/logos/…` в `source-videos/логотипы/<отрасль>/`, обрезаются поля и белый фон,
бренд дописывается в `brands.json`, источник — в `интернет-материалы/АВТОРЫ.md`. Новые папки: `еда/`, `медицина/`, для ОАЭ — `финансы/`, `логистика/`, `авиация/`, `недвижимость/`, `энергетика/` (отрасли сайта finance, logistics, aerospace, realestate, energy).
`--no-logos` — без скачивания.

Автоподгонка: после генерации HTML открывается в Chromium (`шаблон/fit_check.mjs`) и проверяется, что тексты
не вылезают из карточек, а заголовки не ужаты сильнее чем в ~1,6 раза; что не влезло — заменяется более коротким
вариантом (короче по границе фразы, без прилагательных, короткое название) и проверка повторяется. Остаток печатается
как «! не влезает» — тогда поправьте JSON руками. Лист-обзор после сборки всё равно просмотрите.

Проверка на Таиланде: `контент/_проверка-тайланд.json` (конвертер) против ручной `2026-10-08-тайланд.json` —
`готовые/превью/сравнение-конвертер-тайланд.jpg`. Обзор всех 7 презентаций Таиланда — `готовые/превью/страна-тайланд.jpg`.

После конвертера всё равно нужна ручная выверка: тонкие карточки (2 факта) дополняются фактами из описания сайта,
«Почему выбран» с обрывками («Позже, …», «В том же году …») переписывается. Логотипы с подписями сайта
(«企業情報» у PayPay, «西日本» у NTT, «Welding and Handling Robots» у Panasonic) обрезаны до знака компании.

(`оаэ-ии`, `оаэ-финтех`, …). Что добавилось в конвертере: новые отрасли сайта — свои папки логотипов и иконки «Выгод»/«Условий»
(логистика — package, авиация — plane, недвижимость — building, энергетика — zap); региональные хвосты «MENA», «MEA», «Middle East»,
«Middle East & Africa» не мешают найти логотип и сокращают название в днях и на обложке («Google MENA» → Google, «Visa Middle East &
Central Asia» → Visa); подзаголовок тура «от Emaar и Palm Jumeirah до острова Яс» не режется по «и» как перечисление, а регистр
слов в «Выгодах» и «Условиях» — как в названии тура («e-commerce», но «Jebel Ali»); дирхамы: «AED 5,4 млрд» и «305 млрд дирхамов ОАЭ»
→ «5,4 млрд дирхамов», «35 млрд $» → «$35 млрд», подпись «активы»; «превышает / превысили X» → «X+»; «100%-ное владение» без «-ное»;
несклоняемые и составные города («Абу-Даби», «Куала-Лумпур») не портятся в «абу-даби»; тур в одном городе — «Трансферы включены»
вместо «трансферы между городами программы», а без перелётов из «Трансферы/перелёты» убираются «перелёты»; перегон на маршруте —
«≈1,5 ч» вместо «~1,5 часа по трассе», и берётся из трансфера накануне («После утреннего визита — трансфер Абу-Даби → Дубай»);
подпись дня «X — компания, основанная в 2012» без хвоста про основание; обрезка не кончается на «of the» («Mall of the»).
Арабских названий нет: у компаний ОАЭ на сайте поле `name_zh` пустое.

Что добавилось в конвертере и шаблоне: родное название (`native`, призрак `ghost`) берётся из `name_zh`, только если оно на
письме страны, которое есть в шрифтах (китайское для Китая, японское, тайское) — у корейских компаний в `name_zh` китайские
названия («酷澎» у Coupang), а хангыль (есть только у Naver и Woowa Brothers) в шрифтах шаблона отсутствует, поэтому в Корее
родных названий нет; пометки дня в городе («Ульсан, день 1», «Пхохан, финал», в Китае «Шэньчжэнь, день 2 (финал)») убираются —
город один в маршруте, на карточках и подписях; «Осан → Сеул (Букчон)» в маршруте — «Осан»; перегон к городу берётся из текста,
где этот город назван («Днём — переезд в Ульсан (KTX + автобус, ~2,5 ч)» у предыдущего дня; «KTX» — поезд), а не из переезда
дальше; «Почему мы» ищет преимущества по смыслу (раньше в Корее под «Сопровождение и перевод» стоял текст про согласование);
«Оба визита — …» одного дня не приписывается блоку из нескольких дней, а заметка с латинского названия не портится строчной
(«Rakuten Crimson House», «ZOZO»); подпись последнего дня длиннее 20 знаков сокращается до основного города; `fit_check`
проверяет, что подпись дня («Пхёнтхэк · 10:00–13:00») не наезжает на кружок следующего дня и не уходит за край, и тогда
сокращает её (`days.N.sub`; та же проверка нашла наезд в готовых «Таиланд-еда» и «Таиланд-лонгевити», день 2). Шаблон:
«Программа по дням» на 6 дней (`.s-days.n6` — мельче шрифт), «Маршрут» на 5 городов больше не обрезает крайние кружки
и карточки краем слайда. Папки: `electronics`/`telecom` → `техгиганты/`.
Особые случаи Кореи: у Fresheasy на сайте (`/logos/Fresh & Easy.png`) знак американской сети Fresh & Easy — текстовый логотип,
фудтех — с `--no-logos`; у LG Display — латинский `/logos/LG Display.png` вместо корейского «LG디스플레이»; у верфи Hyundai Heavy
Industries — свой `/logos/Hyundai Heavy Industries.png` (на сайте у карточки общий знак Hyundai); у PharmaResearch на сайте знак
дочерней PharmaResearch Bio — слово «Bio» обрезано; у hy (Korea Yakult) — знак Yakult; Samsung d'light и Samsung Innovation
Museum — один файл `техгиганты/samsung.svg`. В турах Кореи на сайте нет проживания в составе — в «Выгодах» вместо
«Проживание N ночей» — «Без перелётов». Обложка «Интернет-гигантов» — по заготовке `контент/2026-10-08-обложка-korea.json`.

## Как устроен шаблон

- Формат слайда — 1920×1080 px, в PDF 1440×810 pt (точно как оригиналы, они тоже свёрстаны в Chromium).
- Шрифты (локальные woff2, OFL): заголовки — **Sofia Sans Extra Condensed 900**, подписи — **Sofia Sans Condensed 850**,
  текст — **Inter 400**, иероглифы — **Noto Sans SC 900**, тайский — **Noto Sans Thai**, вьетнамские буквы заголовков —
  **Saira Extra Condensed 900** / **Barlow Condensed 800** (только недостающие в Sofia Sans знаки).
- Цвета: синий `#1a73e8`, фон `#f3f5f8` (обложка `#f5f7fa`), текст `#17171d` / `#2b2d38` / `#5e6170`,
  голубой `#e6f1fd`, «скотч» `#8fbdf5`, тени карточек — две сплошные полосы `#dce3ec` (+7 px) и `#ebeff5` (+13 px).
- Координаты всех элементов сняты с PDF-примеров (PyMuPDF) и выверены попиксельно:
  `шаблон/сравнение-с-оригиналом.jpg` — оригинал слева, шаблон справа.
- Файлы: `template.html` (каркас), `slides/*.html` (по файлу на тип слайда, Jinja2), `slides/_macros.html`
  (иконки Lucide, логотип, «таблетка»), `slides.css`, `build.py` (сборка), `render.mjs` (Playwright: PDF + PNG),
  `assets/` (робот, голова робота, QR-коды из примеров), `fonts/`.

## Формат JSON

```json
{
  "output": "2026-10-08-тайланд",
  "slides": [ { "type": "cover", ... }, { "type": "company", ... } ]
}
```

Перенос строки в тексте — `\n`. Пути к картинкам — от корня репозитория (`source-videos/...`) или `assets/...`.
В любом слайде можно задать `tag` (синяя «таблетка») и `hero` (другая картинка вместо робота).

| `type` | Слайд (пример) | Поля |
|---|---|---|
| `cover` | Обложка (ИИ стр. 1, Alibaba стр. 1) | `tag`, `title` (по умолч. GLOBAL TECH TOUR), `topright`, `logos[]` {name, logo} до 12 (с `logos_big: N` первые N — крупно в ряд, остальные — мелко вторым рядом) **или** `logo` {name, logo} — один большой; `box_kicker`, `box_text`, `box_right`, `footer` |
| `why` | «Почему мы» (ИИ 2) | `items[4]` {title, text}; 3-й — синяя плашка, 4-й — голубая |
| `layers` | «Направления» (ИИ 3) | `title1`, `title2` (вписываются в колонку), `items[3]` {name, text}, `quote`, `ghost`, `logos[≤3]` {name, logo} — карточки логотипов в свободной левой колонке под заголовком (`logos_layout: "column"` — столбиком, вдвое крупнее; влезает при заголовке в 2 строки, как «3 команды») |
| `route` | «Маршрут» (ИИ 4) | `cities[2–5]` {name, days, companies, leg {icon: plane/train/car, text}}, `footer` (HTML, `<b>` — синим), `ghost` |
| `company` | Карточка компании (ИИ 5–14) | `title`, `native` (иероглифы/тайский), `ghost`, `ghost_thai`, `logo`, `facts[4]` {icon, value, label, sub}, `why`, `learn`, `short`, `subtitle`, `title_dy` (сдвиг заголовка вниз, px) |
| `days` | «Программа по дням» (Alibaba 6) | `title`, `days[2–6]` {label, sub, title, text}, `ghost` |
| `benefits` | «Выгоды» (ИИ 15) | `items[6]` {title, text, icon} |
| `market` | «О рынке» (ИИ 16) | `lead`, `stats[3]` {value, label, sub, frac 0…1 — заполнение дуги}, `quote`, `source`, `ghost` |
| `conditions` | «Формат и условия» (Alibaba 8) | `facts[4]` {icon, value, label, sub}, `includes[]`, `includes_note`, `footer` |
| `steps` | «Как проходит» (Alibaba 11) | `steps[3–5]` {title, text}, `hl` — номер синего шага, `faq[4]` {q, a} |
| `contacts` | «Контакты» (ИИ 17) | `note`, `contacts[6]` {type: email/site/phone/whatsapp/telegram/wechat, text}, `qr[3]` {label, img} |

Иконки (`icon`): briefcase, users, trending, pin, calendar, flag, plane, train, car, headphones, target, building,
store, cart, smartphone, cpu, globe, star, chart, handshake, home, package, mail, phone, chat, send,
zap (энергия), sun (солнце), ship (порт), bank (банк), card (платёжная карта).

`ghost` — бледные крупные знаки на фоне (как 智谱 в примерах): обычно первые 2 иероглифа названия;
для тайских названий — первое слово и `"ghost_thai": true`.

Правило по фактам: в презентацию идёт только то, что есть на сайте globaltechtour.ru или у пользователя.
Нет данных — оставьте явную заглушку `[уточнить …]`.

## Робот на фоне страны

Робот на обложке, «Почему мы», «Выгодах» и «Контактах» стоит на фоне города страны программы. В контенте — одно поле
верхнего уровня `"robot": "bangkok"`: берутся `шаблон/assets/роботы/robot-bangkok.png` (в полный рост) и
`robot-head-bangkok.png` (крупно, зеркально — для «Выгод»). Без поля — исходный робот с Шанхаем (Китай).
Готовые ключи: `bangkok` (Таиланд: Ват Арун, MahaNakhon, Чао Прайя), `india` (Тадж-Махал, Мумбаи), `vietnam`
(Хошимин: Landmark 81, Bitexco, бухта Халонг), `malaysia` (Петронас, KL Tower, Merdeka 118), `japan` (Токийская башня,
Скайтри, Фудзи), `korea` (Сеул: Намсан, Lotte World Tower, Кёнбоккун), `indonesia` (Джакарта: Монас, Боробудур),
`uae` (Дубай: Бурдж-Халифа, Бурдж-эль-Араб, Музей будущего). Исходники генераций — `assets/роботы/<ключ>-raw.png`.
Новая страна: `python3 презентации/шаблон/robot_assets.py <ключ> <ссылка-на-генерацию>` — делает оба файла сам. Новая страна: перерисовка исходного `assets/robot.png`
в Higgsfield (GPT Image 2.5, medium, 2k, 9:16, ~1 кредит; промпт — «то же самое, заменить только город и отражение в очках»,
пример в истории коммитов), затем `robot_assets.py` (обрезка и прозрачные края оригинала).
Отдельное `hero` / `hero_head` в слайде по-прежнему важнее.
