# Знак GTT «кристалл»: как поставить

Знак — гранёный кристалл из логотипа GTT в 3D, надпись по кругу «GLOBAL TECH TOUR · 全球科技之旅» (выбор 01.11.2026).
Всё сделано в максимальном качестве: картинки нарисованы вдвое крупнее и уменьшены, ролики — без видимых стыков.

## Instagram (`instagram/`)

| Файл | Куда |
|---|---|
| `gtt-аватар-1080.jpg` | фото профиля: Профиль → «Редактировать профиль» → «Изменить фото». Кружок Instagram обрежет сам, надпись по кругу помещается целиком |
| `gtt-аватар-мастер-2160.png` | исходник без сжатия (для сайта, презентаций, печати) |
| `хайлайты/01…09-*.jpg` | обложки актуальных: Туры, Кампусы, Заводы, Страны, Отзывы, Как это было, О нас, Заявка, Вопросы |
| `хайлайты/08-Заявка-красная.jpg` | «Заявка» красной печатью 约 — единственный яркий акцент в синем ряду, притягивает взгляд к заявке (вместо обычной `08-Заявка.jpg`) |
| `хайлайты/00-фон-шаблон.jpg` | пустой фон в том же стиле — для нового раздела (или попросите нарисовать предмет) |
| `gtt-stories-заставка-1080x1920.mp4` | живой кристалл на 5 секунд — первой историей в актуальное «О нас» или в начало Stories |

Порядок кружков под продажи: Туры → Отзывы → Заявка → Кампусы → Как это было → О нас → Заводы → Страны → Вопросы
(Instagram ставит новый хайлайт слева — создавайте в обратном порядке).

Обложка актуального: удерживайте кружок актуального → «Редактировать актуальное» → «Изменить обложку» → значок галереи →
выберите картинку. Предмет стоит ровно по центру, двигать не нужно. Видео или GIF на аватар Instagram поставить нельзя —
только картинку; «живым» профиль делают свежие Stories (цветное кольцо вокруг аватара).

## Telegram (`telegram/`)

| Файл | Куда |
|---|---|
| `gtt-аватар-1280.jpg` | фото канала: канал → «Изменить» → «Установить фото или видео» |
| `gtt-видеоаватар-800.mp4` | живой аватар (5 секунд, по кругу): там же → выбрать видео. В списке чатов — кадр, при открытии канала — анимация |

Пересобрать любой файл в другом размере — `reels-studio/tools/gtt-crystal/render.mjs` (команды в `reels-studio/README.md`).
