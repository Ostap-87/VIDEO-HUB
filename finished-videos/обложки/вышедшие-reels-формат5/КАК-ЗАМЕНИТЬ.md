# Обложки вышедших Reels GTT — «формат 5» (01.11.2026)

Через API Instagram обложку вышедшего Reels не поменять — только в приложении (у каждого ролика по 30 секунд):

1. Сохраните картинку из этой папки на телефон.
2. Откройте Reels в профиле GTT → **⋯** → **Изменить** → **Изменить обложку** (или «Обложка»).
3. **Добавить из фотоплёнки** → выберите картинку → проверьте рамку «Обложка в профиле» (3:4 — по центру) → **Готово** → **Сохранить**.
