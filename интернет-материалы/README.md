# Материалы из интернета

Всё, что скачано из интернета для роликов и презентаций (фото, иллюстрации, иконки), хранится здесь, по темам:
- `города/` — фото городов.

У каждого файла должна быть строка в `АВТОРЫ.md`: автор, лицензия, ссылка на источник.
Берём только материалы со свободной лицензией, разрешающей коммерческое использование (CC0, CC BY, CC BY-SA).
В роликах путь к файлу пишется от корня репозитория, например `интернет-материалы/города/pekin.jpg`.
