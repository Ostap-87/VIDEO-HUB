# Звуковые эффекты (`интернет-материалы/звуки/`)

Короткие звуки для моушн-дизайна в стиле маньхуа (03.11.2026). Только лицензии с коммерческим использованием: CC0 1.0 и CC BY 3.0/4.0.
Все файлы: WAV 48 кГц стерео 16 бит, тишина в начале срезана, пик −1 dBFS (по сэмплам). Путь в props — от корня репозитория,
например `интернет-материалы/звуки/whoosh-1.wav`. Авторы и ссылки — также в `интернет-материалы/АВТОРЫ.md`.

**CC BY — указать автора в описании публикации**, если звук есть в ролике: Gregor Quendel (whoosh-4, impact-4, riser-1, riser-2),
Packsmithy (impact-1, impact-2, glitch-1…3, ding-2, beep-1), copyc4t (tension-1). Готовая строка: «Звуки: Gregor Quendel, Packsmithy,
copyc4t (OpenGameArt), CC BY 4.0 / 3.0». CC0 (BigSoundBank — Joseph Sardin, Kenney, artisticdude, Mekaal) — без указания автора.

Папка `zvukitop/` — отдельный набор zvukitop.com (свой README, решение пользователя 03.11.2026).

Описания «как звучит» — по названию звука у автора и замеру сигнала (длина, огибающая, спектр); перед публикацией слушать.
