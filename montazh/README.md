# Монтажная

Приложение для монтажа роликов Instagram и TikTok поверх нашего движка `reels-studio` (решение пользователя 22.10.2026:
«модуль, в который я добавляю сырое видео… всё будет твориться под капотом»). Работает окном на Mac и в браузере.
Предпросмотр — **настоящий шаблон TalkReelPro** в Remotion Player: субтитры, звук, цвет и эффекты видны сразу, без рендера.

## Как пользоваться

1. **Новый ролик**: файл с диска (MOV/MP4 с телефона) или ссылка — Google Диск, Яндекс Диск, Dropbox, WeTransfer,
   прямая. Проект: GlobalTechTour, Aura Robotics или ostapdotcenko.ru.
2. **Исходник**: кадры, волна звука, формат (Reels/TikTok или Stories), линия глаз — нажать на глаза в кадре.
3. **Текст**: «Распознать речь» (Whisper прямо в окне; модель скачивается один раз) или загрузить готовые
   субтитры (.json, .srt). Стиль субтитров (фирменные / 3D), размер, высота. Слово — переход к нему, двойной
   щелчок — исправить.
4. **Звук**: «Как снято» / «Чистый голос» (шумодав RNNoise + эквалайзер + компрессор) — переключение сразу слышно
   в предпросмотре. Музыка и громкость.
5. **Цвет**: 9 вариантов цветокоррекции на кадрах ролика; выбранный сразу в предпросмотре; сила 0–150 %.
   **Цвета текста**: готовые сочетания (субтитры + акцент + текст на акценте, проверены на читаемость) или свои цвета —
   окно подсказывает, читается ли текст на тёмном/светлом кадре и сочетаются ли цвета (родственные, противоположные).
6. **Монтаж**: монтажный стол (кадры, звук, субтитры, эффекты, заметки).
   - **Строка команд** сверху — пишете или говорите (🎤), эффект сразу в предпросмотре:
     «на 12 секунде приблизь», «отдали плавно на 2 секунды», «смайл огонь», «эмодзи 😂 дождём», «хук «МОИ» за головой»,
     «на словах «пять дней» цифра «5 дней»», «с 0:20 по 0:24 картинка завод роботов кругом», «ч/б на 2 секунды»,
     «спикера в круг справа сверху», «вырежи меня по контуру и в левый нижний угол», «экран снизу с картинкой «завод»»,
     «текст «КИТАЙ» на стене под углом 30 градусов», «стикерами: Дорога, Отель, Заводы», «субтитры жёлтые, акцент красный».
     Время: «на 12 секунде», «в 1:05», «с 20 по 24 секунду», «на словах «…»»; без времени — на курсор. «Отменить» —
     вернуть как было. Что не понято — заметка для Claude (жёлтая на столе), выполняется при рендере.
   - Или вручную: курсор на секунду → эффект из библиотеки → у эффекта время, текст, картинка, ползунки (размер,
     положение, поворот по трём осям), цвета.
   - **Картинки по смыслу** (вкладка «Перебивки» и у любого эффекта с картинкой): каталог генераций Higgsfield
     (777 шт.) ищется по смыслу фразы — «Под фразу», поиск словами или «Расставить сам по всему ролику» (перебивка
     примерно раз в 9 с, переходы по кругу). Уже стоявшие в роликах и запрещённые картинки не предлагаются.
   - **Заметки** по секундам: «здесь логотип», «вырезать оговорку» — их делает Claude.
7. **Библиотека**: каждый эффект — превью 1–2 с. Референсы → новые эффекты (присылаете ролик, я разбираю приёмы).
8. **Готово**: **«Сделать ролик»** — видео и задание уходят в облако (GitHub Actions), там: студийный звук DeepFilterNet,
   вырезка пауз и «эканий» (галочка), вырезка спикера для эффектов «за головой» и «по контуру», рендер Reels или Stories
   (части до 60 с), копия для телефона до 29 МБ и раскадровка. Ход работы и готовый ролик — в карточке задания:
   смотреть прямо в окне и «⬇ Скачать». Обычно 10–25 минут; окно можно закрыть. Без сервера Mac — «Скачать задание»
   и прислать Claude в чат.

### Эффекты библиотеки

| Вкладка | Эффекты |
|---|---|
| Движение | резкий наезд, плавный наезд, **отдаление** (сила: чуть / обычно / сильно) |
| Спикер | **в угол** (рамка), **в круге**, **по контуру** (вырезка с обводкой); куда (9 мест), размер, фон (размытие / бренд / тёмный / картинка), поворот в 3D |
| Экраны | **снизу, сверху, сбоку, из угла** — с вашим видео или фото (или картинкой каталога), размер, подпись; спикер отодвигается |
| Переходы | заливка из угла, ч/б → цвет |
| Титры | хуки (за головой, стена 3D, гротеск + курсив, слова по одному), **текст в 3D** (на стене, лёжа, под углом, от руки): размер, положение, наклон по трём осям, шрифт, цвет и объём, за спикером или перед ним |
| Эмодзи | 40 живых эмодзи Google Noto: выскакивает, всплывает, трясётся, россыпь; место — не на лице |
| Списки | планшет с галочками, **флипчарт**, **карточки стопкой**, **стикеры**, **крупные номера**, **пилюли вокруг головы**, **печатная машинка** |
| Графика | крупная и красная цифра, плашки (с зачёркиванием), графики роста и падения, стрелка «Ссылка выше» |
| Перебивки | круг, въезд сбоку, наезд, шторка, спикер в углу, спикер в экране |
| Цвет | цвета текста на отрезке (субтитры, акцент) |

### Ключ GitHub для «Сделать ролик» (один раз)

github.com → Settings → Developer settings → **Fine-grained token**: имя «Монтажная», срок 1 год, Repository access →
Only select → `Ostap-87/VIDEO-HUB`, Permissions → Contents → **Read and write** → Generate → вставить в окне на шаге
«Готово». Ключ хранится только на Mac (`~/Library/Application Support/Montazh/github.json`, доступ 600), в окно не
возвращается; в чат его не присылать.

Проекты хранятся в окне приложения (IndexedDB), никуда не уходят, пока их не отправить в работу.

## Установка на Mac

```bash
D=$(mktemp -d) && curl -fL https://codeload.github.com/Ostap-87/VIDEO-HUB/tar.gz/refs/heads/montazh-dist | tar -xzf - -C "$D" --strip-components=1 && bash "$D/install_mac.command"
```

Значок «Монтажная» — на рабочем столе и в «Программах». Нужен Python 3.9+ (python.org) — для встроенного сервера.
Окно — Chrome / Яндекс Браузер / Edge в режиме приложения (видео iPhone в HEVC играет), без них — движок Safari.
Обновление — та же команда. Журнал: `~/Library/Logs/Монтажная.log`.

В браузере — GitHub Pages репозитория (после включения Pages: Settings → Pages → Source: GitHub Actions).
В браузере по ссылке видео по ссылке не скачивается (это делает сервер Mac или движок) — файл с диска работает.

## Как устроено

- `app/` — React + `@remotion/player`; пакеты берутся из `reels-studio/node_modules`, свой `npm install` не нужен.
  - `props.ts` — проект → props `TalkReelPro` (тот же JSON рендерит движок); `effects.ts` — библиотека эффектов
    (каждый — готовый приём TalkReelPro и функция `apply`); `grades.ts` — пресеты цвета (CSS-фильтры = поле `grade`);
    `audio.ts` — шумодав RNNoise (`vendor/rnnoise-sync.js`, Apache-2.0) и студийная цепочка WebAudio;
    `transcribe.ts` — Whisper (transformers.js с jsDelivr, модель с huggingface.co или hf-mirror.com);
    `media.ts` — кадры, звук, волна (mediabunny для MOV); `store.ts` — проекты и файлы в IndexedDB.
  - Файлы проекта (видео, чистый звук, картинки) шаблон получает через `window.remotion_staticFiles` (подмена
    `staticFile()` по имени), файлы шаблона (звуки, музыка, страницы сайта) — `assets/` сборки
    (`window.remotion_staticBase`).
- `build.mjs` — сборка: `node montazh/build.mjs [--out <папка>] [--dev] [--watch]`.
- `library/previews/<id>.mp4` — превью эффектов: `node montazh/scripts/render_previews.mjs [--only id,…]`
  (все эффекты на образце GTT «Чай и кофе», один рендер, нарезка ffmpeg; вырезка спикера — `npm run matte`).
- `app/commands.ts` — разбор команд словами (время + слова эффектов, без нейросети); `emoji.ts` — 40 живых эмодзи
  (`интернет-материалы/эмодзи/`, Google Noto, CC BY 4.0); `images.ts` — картинки по смыслу (каталог
  `library/images.json`, векторы `library/images.emb`, миниатюры `library/images/`; модель
  Xenova/paraphrase-multilingual-MiniLM-L12-v2 в окне); `palettes.ts` — сочетания цветов и проверка контраста.
  Каталог и векторы пересчитываются `python3 montazh/scripts/build_images.py` (после новых генераций Higgsfield).
- `mac/` — `montazh_server.py` (127.0.0.1:8740: приложение, скачивание по ссылкам через curl, отправка задания:
  файлы → релиз GitHub `montazh-<id>`, задание → `montazh/jobs/<id>.json`; ход работы — `status.json` релиза),
  `montazh_window.py` (окно), `install_mac.command`, иконка (`make_icon.py`).
- `engine/run_job.py` — движок задания (GitHub Actions «Монтажная — рендер», `.github/workflows/montazh-render.yml`,
  запускается сам на каждое новое `montazh/jobs/*.json`; повтор — Run workflow с id): файлы релиза → `npm run cut`
  (звук, HDR → bt709, паузы) → props на шкалу склейки → `npm run matte` на нужные отрезки → рендер → копия для
  телефона, раскадровка, части Stories → в тот же релиз. Локально: `python3 montazh/engine/run_job.py <id> --local <папка>`.
  Образец для проверки движка — `montazh/engine/sample.mp4` (12 с, iPhone HLG), задание `montazh/jobs/proverka1.json`
  (`files.sourceRepo` — исходник из репозитория вместо релиза); повторить — Actions → «Монтажная — рендер» → id `proverka1`.
- `.github/workflows/montazh.yml` — сборка на каждый пуш в `montazh/` и `reels-studio/src/`: ветка `montazh-dist`
  для Mac и GitHub Pages.

## Дальше

- Референсы → разбор приёмов → новые эффекты в библиотеке с превью (ролик по ссылке или файлом).
