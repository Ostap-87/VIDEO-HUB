# Монтажная

Приложение для монтажа роликов Instagram и TikTok поверх нашего движка `reels-studio` (решение пользователя 22.10.2026:
«модуль, в который я добавляю сырое видео… всё будет твориться под капотом»). Работает окном на Mac и в браузере.
Предпросмотр — **настоящий шаблон TalkReelPro** в Remotion Player: субтитры, звук, цвет и эффекты видны сразу, без рендера.

## Как пользоваться

1. **Новый ролик**: файл с диска (MOV/MP4 с телефона) или ссылка — Google Диск, Яндекс Диск, Dropbox, WeTransfer,
   прямая. Проект: GlobalTechTour, Aura Robotics или ostapdotcenko.ru.
2. **Исходник**: кадры, волна звука, формат (Reels/TikTok или Stories), линия глаз — нажать на глаза в кадре.
3. **Текст**: «Распознать речь» (Whisper прямо в окне; модель скачивается один раз) или загрузить готовые
   субтитры (.json, .srt). Стиль субтитров (фирменные / 3D), размер, высота. Слово — переход к нему, двойной
   щелчок — исправить.
4. **Звук**: «Как снято» / «Чистый голос» (шумодав RNNoise + эквалайзер + компрессор) — переключение сразу слышно
   в предпросмотре. Музыка и громкость.
5. **Цвет**: 9 вариантов цветокоррекции на кадрах ролика; выбранный сразу в предпросмотре; сила 0–150 %.
6. **Монтаж**: монтажный стол (кадры, звук, субтитры, эффекты, заметки). Курсор на нужную секунду → эффект из
   библиотеки → сразу в предпросмотре; у эффекта — время, текст, картинка. **Заметки** по секундам: «здесь
   логотип», «вырезать оговорку» — их делает движок.
7. **Библиотека**: каждый эффект — превью 1–2 с. Референсы → новые эффекты (присылаете ролик, я разбираю приёмы).
8. **Готово**: сводка и задание (`.job.json`) — всё выбранное: стиль, звук, цвет, эффекты по секундам, заметки и
   props шаблона.

Проекты хранятся в окне приложения (IndexedDB), никуда не уходят, пока их не отправить в работу.

## Установка на Mac

```bash
D=$(mktemp -d) && curl -fL https://codeload.github.com/Ostap-87/VIDEO-HUB/tar.gz/refs/heads/montazh-dist | tar -xzf - -C "$D" --strip-components=1 && bash "$D/install_mac.command"
```

Значок «Монтажная» — на рабочем столе и в «Программах». Нужен Python 3.9+ (python.org) — для встроенного сервера.
Окно — Chrome / Яндекс Браузер / Edge в режиме приложения (видео iPhone в HEVC играет), без них — движок Safari.
Обновление — та же команда. Журнал: `~/Library/Logs/Монтажная.log`.

В браузере — GitHub Pages репозитория (после включения Pages: Settings → Pages → Source: GitHub Actions).
В браузере по ссылке видео по ссылке не скачивается (это делает сервер Mac или движок) — файл с диска работает.

## Как устроено

- `app/` — React + `@remotion/player`; пакеты берутся из `reels-studio/node_modules`, свой `npm install` не нужен.
  - `props.ts` — проект → props `TalkReelPro` (тот же JSON рендерит движок); `effects.ts` — библиотека эффектов
    (каждый — готовый приём TalkReelPro и функция `apply`); `grades.ts` — пресеты цвета (CSS-фильтры = поле `grade`);
    `audio.ts` — шумодав RNNoise (`vendor/rnnoise-sync.js`, Apache-2.0) и студийная цепочка WebAudio;
    `transcribe.ts` — Whisper (transformers.js с jsDelivr, модель с huggingface.co или hf-mirror.com);
    `media.ts` — кадры, звук, волна (mediabunny для MOV); `store.ts` — проекты и файлы в IndexedDB.
  - Файлы проекта (видео, чистый звук, картинки) шаблон получает через `window.remotion_staticFiles` (подмена
    `staticFile()` по имени), файлы шаблона (звуки, музыка, страницы сайта) — `assets/` сборки
    (`window.remotion_staticBase`).
- `build.mjs` — сборка: `node montazh/build.mjs [--out <папка>] [--dev] [--watch]`.
- `library/previews/<id>.mp4` — превью эффектов: `node montazh/scripts/render_previews.mjs [--only id,…]`
  (все эффекты на образце GTT «Чай и кофе», один рендер, нарезка ffmpeg; вырезка спикера — `npm run matte`).
- `mac/` — `montazh_server.py` (127.0.0.1:8740: приложение + скачивание по ссылкам через curl),
  `montazh_window.py` (окно), `install_mac.command`, иконка (`make_icon.py`).
- `.github/workflows/montazh.yml` — сборка на каждый пуш в `montazh/` и `reels-studio/src/`: ветка `montazh-dist`
  для Mac и GitHub Pages.
