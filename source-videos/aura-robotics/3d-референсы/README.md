# Референсы 3D-моделей Aura (от пользователя, 12.10.2026)

По ним нарисованы 3D-модели арсенала роликов в стиле Aura (пергамент / графит / лимонный акцент, лак, шарниры),
код — `reels-studio/src/components/aura3d/`, описание — `reels-studio/CLAUDE.md`, раздел «3D-арсенал Aura».
Чужие логотипы и надписи с референсов (EDS Robotics, IRON MAC, Unitree, номера на корпусах) в модели не переносим.

| Файл | Что | Модель |
|---|---|---|
| `agv.webp` | AGV-тележка: низкий корпус, бампер, окно лидара, площадка с профилями | `AuraAgv` — ездит, разворачивается, поднимает площадку, подвозит коробки |
| `manipulyator.png` | 6-осевой промышленный манипулятор с пружиной-противовесом | `AuraArm` — двигается в разных плоскостях, берёт и переносит коробки |
| `robosobaka.png` | Робособака (как Unitree Go2): корпус с «лицом»-сенсорами, моторы бёдер, изогнутые голени | `AuraDog` — ходит, встаёт на задние лапы, танцует |
| `roboruka.png` | Роборука: фаланги, шарниры со светящимися кольцами | `AuraHand` — шевелит пальцами, берёт предмет двумя пальцами и переносит |
| `gumanoid.webp` | Гуманоид: шлем с визором, белые панели и тёмно-синие вставки, красные акценты | `AuraHumanoid` — ходит, машет, показывает, приглашает жестом, кивает; кисти — роборука `AuraHand` |

Скины ближе к референсам (05.11.2026, `skin` у моделей): манипулятор `industrial` (белая эмаль, моторы-коробки, гофра пружины — Титан)
и новый дизайн `cobot` (Тихон), роборука `chrome` (чёрный хром, красные кольца — Рубин), AGV `orange` (оранжевый с чёрным — Рыжик),
гуманоид `navy` (белый, тёмно-синий, красный — Нова). Логотипы и надписи референсов по-прежнему не переносим. Вся команда —
`reels-studio/CLAUDE.md`, «Команда Aura».
