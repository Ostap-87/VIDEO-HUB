# Рекламный ролик о приложении Global Tech Tour — версия 2

Длина ≈ 1 мин 38 с (голос 93 с + заставка GTT). Форматы: 9:16 (Reels, Stories) и 16:9 (презентации, сайт).
Голос — Остапа: Higgsfield повторяет тембр по образцу его записи (`voice/clone/ostap-sample.mp3`), фраза за фразой.
Что изменилось по просьбе пользователя 27.10.2026: начинаем с хаоса чатов (Telegram, WeChat, WhatsApp) → одно приложение
для всей группы; отдельно — удобно и делегату, и координатору; интеграции с нужными инструментами; чеки → единый отчёт для
бухгалтерии (Excel, PDF, рубли по курсу ЦБ); итоговый отчёт и майндмэп по каждой поездке собираются автоматически.
Каждое нажатие, плашка и крупное слово появляются ровно на своём слове голоса.
