# Роль

Ты делаешь ролики Instagram Reels для GlobalTechTour (globaltechtour.ru) на Remotion
в этом проекте. Все ролики должны выглядеть как один канал. Ядро стиля менять нельзя:
любое решение сверяй с этим документом.

# Бренд и аудитория

- Бренд: GlobalTechTour. По текущим материалам: экспедиции на производства и в технокомпании Китая. Если тема шире, уточни у меня.
- Аудитория: широкая, кому интересны технологии. Пиши без жаргона, термин объясняй одной фразой.
- Язык: русский.
- Тон — сочетание четырёх: хук интригующий (конкретный факт или противоречие), подача живая и разговорная, факты с цифрами и разбором, всё по делу и без хайпа.

# Формат

- 1080×1920, 30 fps, длина 30–60 секунд.
- Безопасная зона Instagram: сверху 250 px, снизу 380 px, по бокам 64 px. Текст не заходит под интерфейс. Проверяй через `showSafeZone`.
- Структура: хук 0–3 с, основная часть, финал последние ~3 с (заголовок + синяя плашка CTA).
- Финальный CTA всегда ведёт на сайт globaltechtour.ru. Текст плашки по умолчанию: «Подробности на сайте».

# Ядро стиля («светлый framed», закреплён 21.09.2026). Не менять

Цвета (только из `src/theme.ts`):
primary #EEEEF2 фон сцены, accent #2563EB акценты и плашка CTA, text #17171D основной текст,
muted #6B6B76 подписи, surface #FFFFFF плашки, line #D5D5DD рамки.

Шрифты (`src/fonts.ts`):
- Заголовки: Unbounded 700.
- Основной текст: Inter 400, акцент Inter 700.
- Кикер, плашка сайта, счётчик: моноширинный (JetBrains Mono 500, в гайде шрифт не назван).

Кадр:
- Фото или видео всегда в карточке: отступы 48 / 200 / 48 / 200, скругление 64, рамка 2 px line, мягкая тень.
- Не заливать фото тёмным градиентом.
- Внизу карточки светлая дымка (blur 30 px, полупрозрачная, ~64% высоты) под текстом.
- Плашка сайта слева-сверху: `tone: light` на светлом кадре, `dark` на тёмном или ярком.
- Счётчик «1 / 3» справа-сверху в сериях и каруселях.
- Другой брендинг (логотип, водяной знак) не добавлять. Только плашка сайта.

Типографика:
- Кикер: моно 30 px, капс, трекинг 0.14em, accent.
- Заголовок: Unbounded 700, 96 px, межстрочный 1.04.
- Подзаголовок: Inter 400, 44 px, muted.
- Основной текст: Inter 400, 56 px, межстрочный 1.36.
- Акцент: слова в `**двойных звёздочках**` красятся в accent. Один акцент на экран.

# Субтитры (говорит человек в кадре)

Три режима, чередуются по смыслу:
1. По 3 слова, текущее слово accent (Unbounded 700, 72 px). Режим по умолчанию для обычной речи.
2. Фразой целиком (Inter 400, 56 px, акцентные слова Inter 700 синим). Для объяснений и длинных мыслей, смена по смыслу.
3. Одно слово крупно (Unbounded 700, ~140 px, с «попом»). Для цифры или ключевой мысли.

Правила чередования:
- В одной сцене один режим. Режим меняется не чаще, чем раз в ~4 секунды.
- Режим 3 — не чаще одного раза за 8–10 секунд.
- Субтитры не перекрывают плашки списка и не заходят ниже безопасной зоны.
- В тишине субтитров нет: группа из 3 слов рвётся на паузе дольше 0,7 с (`BigCaptions`), поэтому конец фразы не висит
  через паузу и поверх перебивки без речи (ролик SANY 25.10.2026). `captionsAt` style `none` — субтитры на отрезке
  убраны совсем (например, на время планшета `checklists`, когда пункты повторяют речь, а спикер поднят и субтитры
  легли бы на лицо).

# Анимация и эффекты

Динамика средняя: плавно + акцентный «поп» на цифрах и ключевых словах.

- Базовое появление: слова по очереди, снизу вверх на 40 px, пружина snappy (damping 18, stiffness 180, mass 0.8), шаг 2–3 кадра.
- «Поп»: пружина с лёгким перелётом (масштаб 0.8 → 1.08 → 1). Только на accent-словах и цифрах, не чаще одного раза в ~3 секунды.
- Смена слайдов в TextReel: новый слайд наезжает справа за 14 кадров.
- Фото: медленный наезд 1.0 → 1.08 за длину сцены. Видео не масштабируем.
- Финал: плашка CTA выезжает снизу справа.
- Стоп-листа эффектов нет: тряска, глитч, свечение, резкие зумы, эмодзи, стикеры разрешены.
  Правило дозировки (предложение, можно снять): ядро стиля неизменно, а акцентные эффекты используются редко,
  не больше одного на сцену и только если усиливают смысл. Эффект на фоне нарушенного ядра (другой шрифт, цвет, рамка) недопустим.

# Цифры и факты (миксуем три приёма)

1. Цифра внутри фразы синим акцентом (по умолчанию для всех цифр).
2. Крупная цифра на весь кадр: Unbounded 700 ~220 px, с «попом», под ней подпись muted.
3. Счётчик: число набегает от нуля за ~1.2 с с замедлением к концу.
Главный факт ролика — приём 2 или 3, один на ролик. Остальные цифры — приём 1.

# Шаблоны

1. **Разбор / рассказ**: человек в кадре, обложка 3 с, субтитры (3 режима), финал.
2. **Список «топ-3 / топ-5»**: видео идёт, пункты всплывают плашками поверх.
   Плашка: белая полупрозрачная с blur, как плашка сайта; номер Unbounded 700 синим, подпись Inter.
   Плашка появляется, когда о пункте начинают говорить, уходит через ~4 с, одновременно не больше двух.
3. **Репортаж с производства**: видео с титрами: кикер с локацией и названием, короткие подписи Inter, цифры по правилам выше.
4. **Факт или цитата одной фразой**: cover-слайд: кикер, заголовок Unbounded с акцентом, подзаголовок, финал с CTA.

Новые шаблоны собираются только из существующих компонентов (Frame, Hook, Captions, Cta, RichWords, Media).

# Материалы и звук

- Фото и видео: любые, главное по теме. Если кадр тёмный или пёстрый, ставь `tone: dark` на плашке сайта.
- Звук: человек говорит в кадре + музыка. Музыку подбирай под каждый ролик, тише голоса (около 15–20% громкости, можно поправить). Только треки с лицензией для коммерческого использования, источник уточняй у меня.

# Правила работы

1. Перед сборкой запроси недостающее: тему, сырьё (видео, фото), хронометраж, ключевой факт, данные.
2. Если для ролика не хватает данных, спрашивай меня. Ничего не выдумывай: ни факты, ни цифры, ни названия компаний.
3. Не меняй `src/theme.ts` и `src/fonts.ts` без прямого указания.
4. Каждый ролик оформляй как props-файл `props/имя.json` для композиции Reel, TextReel или TalkReel.
5. Проверяй безопасную зону и читаемость текста на дымке.
6. Рендери и показывай результат: `npx remotion render src/index.ts Reel ../finished-videos/имя.mp4 --props=./props/имя.json`.
7. Папки: сырьё бери из `source-videos/` (public-папка Remotion — корень репозитория, в `mediaSrc` путь от корня: `source-videos/...`), готовые ролики и обложки сохраняй в `finished-videos/`. Видео и аудио идут через Git LFS.
8. Показывай процесс скриншотами: после каждого рендера или правки нарезай раскадровку. Раскадровку финального ролика
   сохраняй в репозиторий: `finished-videos/раскадровки/имя.jpg` (черновые остаются в `finished-videos/frames/`, вне git).
  
   `npm run frames -- ../finished-videos/имя.mp4` (кадр каждую секунду; `--every 2`, `--at 0.5,3,7`)
   и сразу показывай её мне в чате. Исходник от меня тоже сначала режь на кадры и показывай, что в нём видно.
9. Всё сохраняй в репозиторий `Ostap-87/VIDEO-HUB`, ветка `main`: коммить и пушь после каждого исходника, готового ролика или правки.
10. Новая возможность = обновлённые правила в том же коммите: этот файл (как пользоваться + «Статус реализации»), README и при необходимости корневой `CLAUDE.md`.

# Пакеты Remotion

Справочник API: https://www.remotion.dev/docs/api (из облака читается через curl, а также скиллом `remotion-docs`).
Все `remotion` и `@remotion/*` закреплены на одной версии (сейчас 4.0.533) без `^`. Новый пакет ставь только
командой `npx remotion add <пакет>`, обновление — `npm run upgrade`; после — `npx remotion versions` должен быть без ошибок.

Установлены и для чего:
- `@remotion/media` — рекомендуемые `<Video>` и `<Audio>` для новых компонентов;
- `@remotion/transitions` — `<TransitionSeries>`, переходы между сценами (наезд слайдов, fade, slide);
- `@remotion/captions` — тип `Caption` и разбивка субтитров на страницы (`createTikTokStyleCaptions`) для трёх режимов субтитров;
- `@remotion/elevenlabs` — превращает ответ ElevenLabs Speech to Text в массив `Caption`;
- `@remotion/install-whisper-cpp` — локальная расшифровка Whisper.cpp (бесплатно, модель с Hugging Face);
- `@remotion/sfx` — звуковые эффекты без указания авторства (вжух, щелчки) для «попа» и переходов;
- `@remotion/layout-utils` — измерение текста: подгонка заголовков под ширину карточки;
- `@remotion/motion-blur`, `@remotion/noise` — размытие в движении и шум для акцентных эффектов (дозировано).

# Расшифровка речи (Whisper)

- Один раз за сессию, если нет папки `whisper.cpp/`: `npm run setup:whisper` (сборка ~3 мин + модель ~550 МБ, папка в git не идёт).
- `npm run transcribe -- ../source-videos/папка/clip.mp4` → рядом `clip.words.json` со словами и таймингами в секундах
  от начала исходника. Его содержимое идёт в поле `words` props-файла. Язык по умолчанию `ru` (`--lang auto` для других).
- Скорость: ~1 минута на запуск + ~1 минута на каждые 30 с речи. Бесплатно, без ElevenLabs.
- Перед вставкой проверь текст глазами: названия компаний, цифры и термины Whisper может написать неверно. Исправляй по смыслу,
  сомнительное уточняй у меня.
- В облаке Node.js не скачивает с Hugging Face (тот же запрет, что и для браузера Remotion), поэтому модель качается curl'ом
  в `setup-whisper.sh`; `downloadWhisperModel()` из `@remotion/install-whisper-cpp` в облаке не использовать.

# Быстрый пайплайн: прислали ролик → сразу собираю (решение пользователя 08.10.2026)

Пользователь хочет, чтобы присланный ролик сразу шёл в работу под нужную тему со всеми эффектами и это было быстро.
Порядок, без лишних вопросов:
1. **Сразу запускаю** (в фоне, `setsid nohup … > /tmp/auto-<имя>.log`, слежу через Monitor по строкам `▶|AUTO_|PREP_|REELS|STORIES`):
   `cd reels-studio && python3 scripts/auto.py <ссылка> --theme <тема> --until prep`
   Тему определяю по словам пользователя или названию файла/ссылки (`avto`, `ai`, `byt-tehnika`, `chai-kofe`, `konditerka`,
   `kosmetika`, `novyi-riteil`, `tech-giganty`; новая отрасль или визитка — `obshchee`). Не ясно — беру `obshchee` и уточняю
   у пользователя параллельно, работу не останавливаю. Имя по умолчанию `<сегодня>-<тема>`; второй ролик той же темы в
   тот же день — `--name <сегодня>-<тема>-2`.
2. Пока идёт расшифровка — показываю раскадровку исходника (`finished-videos/frames/<имя>-исходник.jpg`).
3. **Проверка черновика (~5 минут, главное ручное место):** `source-videos/<имя>/_work/<клип>.auto.md` — все элементы по
   времени с фразами и список «Проверить»; лист `_work/<клип>.sheet.jpg` — **глазами** каждую картинку (чужие бренды,
   искажённые надписи, другие страны) и каждый логотип. Правлю:
   - перебивки: `npm run broll -- <имя> --find "…"`, `--set <сек> <номер>`, `--drop <сек>`, плохую картинку — `--block <номер> "<причина>"`;
   - тексты плашек, цифр, чек-листов, ошибки Whisper в словах и названиях — прямо в `props/<имя>.json`;
   - бренд без логотипа (строка «Латинские слова без логотипа») — логотип в `source-videos/логотипы/<отрасль>/` +
     запись в `library/brands.json`, затем `npm run autoprops -- --name <имя> --theme <тема> --clip <клип> --force`;
   - тематическое, чего нет в библиотеке (своя цифра, свой список, график), — добавляю руками по словам речи.
   Лист и короткую сводку показываю пользователю в чате, но рендер не жду: если сомнений нет — сразу дальше.
4. Рендер: `python3 scripts/auto.py --name <имя> --render` (после правки перебивок — сначала
   `python3 scripts/auto.py --name <имя> --until prep --rematte`). Рендер Reels → раскадровка → Stories → части до 60 с →
   лёгкие копии. По `REELS` — смотрю раскадровку, коммичу и отправляю Reels; по `AUTO_DONE` — Stories.
5. Всё, что пополнилось (логотипы, бренды, фразы, заблокированные картинки), коммичу вместе с роликом: следующий ролик
   соберётся точнее.

Из чего собирается черновик (`scripts/autoprops.py`, библиотека `library/`):
- `brands.json` — 60+ брендов: варианты написания (как пишет Whisper и по-русски) → логотип из `source-videos/логотипы/<отрасль>/`.
  Логотип без пустых полей: после добавления — `python3 scripts/trim_logos.py --apply` (режет белые и прозрачные поля,
  цветные плашки бренда оставляет); иначе на карточке и в бейдже карусели он выглядит мелким.
  Подряд названные бренды — до 4 карточек; «работал в Alibaba и Сбере» — карточка-переворот; кириллица («Сяоми») в субтитрах → латиница;
- `cities.json` — города (падежи) → фото; панель городов, если подряд названо 2+ города;
- `phrases.json` — стандартная вторая половина ролика: «Остап Доценко», «10+ лет», «Свободный китайский», «Знаком лично»,
  «Туда, куда с улицы не пускают», «Бесконечные переписки / Ожидание ответов» с зачёркиванием, «1000+ компаний»,
  «18 индустрий», чек-листы «Как устроена поездка», «Условия», «Для кого поездка» (перечисление перед «Заходите на сайт»),
  «Пять дней, N …» — крупной цифрой, финал на «Заходите на сайт». Новая повторяющаяся фраза → сюда;
- `themes.json` — тема: страница экспедиции и скриншоты маршрута, музыка, папки логотипов, какие картинки Higgsfield
  подходят и какие русские слова речи каким словам описания соответствуют, график за спиной (`stockDrop`), акцентные слова;
- `music.json` — треки и громкость; `blocked-images.json` — картинки, которые нельзя ставить;
- перебивки: без повторов (реестр `использовано.json`), без других стран, роботы/переговорные только к месту, 3:4 в приоритете;
  каждые ~8–10 с на фразе 2–4,5 с, не на городах, чек-листах, графике и финале; переходы по кругу;
- зумы: резкие на цифрах, зачёркиваниях и «не пускают», плавные на началах фраз, не чаще раза в 5 с; центр — линия глаз;
- конфликты разводятся сами: плашка ждёт, пока уйдёт цифра; цифра не под логотипами; чек-лист заканчивается до следующей плашки;
- Stories режутся на концах фраз, части до 59,5 с. Рендер в 4 потока (на 11% быстрее двух).

Установка инструментов (Whisper, OpenCV <5, ONNX, модель вырезки, npm) — `scripts/setup.sh`; запускается сама в фоне
при старте каждой сессии (хук `SessionStart` в `.claude/settings.json`, лог `/tmp/gtt-setup.log`), `auto.py` её дожидается.

# Говорящая голова: TalkReel (пайплайн)

Для видео, где человек говорит в кадре одним планом. Порядок:
1. Исходник → `source-videos/ДАТА-тема/`, раскадровка исходника (`npm run frames -- … --every 4`) → показать.
2. `npm run transcribe -- ../source-videos/ДАТА-тема/clip.MOV` → `clip.words.json`. Проверить и исправить названия
   (Whisper путает бренды и города), сомнительное — спросить. Показать текст.
3. `npm run cut -- ../source-videos/ДАТА-тема/clip.MOV --words ../source-videos/ДАТА-тема/clip.words.json`:
   чистит звук (срез <80 Гц, шумоподавление, компрессия, ~-14 LUFS) и вырезает паузы >0,35 с с запасом 0,12 с.
   Результат в `_work/` (в git не идёт): `clip.cut.mp4`, `clip.cut.json`, `clip.cut.words.json`.
   `--words-only` — пересчитать только слова без перекодирования. Показать: спектр до/после, таймлайн вырезанного.
4. Сайт для финала: `npm run site -- https://globaltechtour.ru ../source-videos/ДАТА-тема/site/site.png`.
5. Props `props/ДАТА-тема.json` для композиции `TalkReel`:
   - `slides` — наезды экрана сверху/снизу (`from: top|bottom`, чередовать) в начале смысловых блоков, примерно раз в 10–15 с;
     звук наезда `slideSfx` — whoosh из `@remotion/sfx`, скачанный в `sfx/` папки ролика (громкость 0.35);
   - `site.at` — момент слов «заходите на сайт»: сайт въезжает снизу в карточку и прокручивается;
   - хук — только факты из речи спикера; CTA — последние `ctaSeconds`.

- `kit.tsx` — общий набор: материалы маскота (экспортируются из `AuraMascot.tsx`), скруглённые корпуса `RBox`, `Capsule`,

- `AuraAgv.tsx` — **AGV** (`AgvModel`, ~2 × 1,4 ед.): пергаментный корпус с лимонной полосой, графитовый бампер, окно
  лидара, диоды (мигают на ходу), ведущие колёса со спицами, алюминиевая площадка с отверстиями и профилями, подъёмник.

  на развороте — в разные стороны), `lift` — ключи подъёма площадки 0…1, `boxes` — коробки стопкой в начале,
  `loads` — моменты, когда сверху опускается ещё одна, `unloads` — верхняя съезжает назад и остаётся на полу.
- `AuraArm.tsx` — **манипулятор** 6 осей (`ArmModel`, рост ~3,7 ед.): основание, колонна, плечо с мотором и пружиной-
  противовесом, локоть, предплечье, запястье, двухпальцевый захват на направляющей. План `keys`: `{at, p: [x,y,z]}` —
  куда поставить центр захвата (обратная кинематика `armIK`, «локоть вверх»), `tool` — наклон захвата (π вниз, π/2
  вперёд), `j4` / `j6` — вращение предплечья / захвата, `grip` — раскрытие пальцев (0,5 открыт, по ширине коробки —
  держит), или `{at, j: [j1, α2, α3, j4, α5, j6]}` — суставы напрямую (движения «в разных плоскостях»); между ключами —
  плавно по суставам. `items` — коробки: `start`, `s`, `carry: [[от, до]]` — когда в захвате (`armTip` — где центр захвата).
- `AuraDog.tsx` — **робособака** как Go2 (`DogModel`, длина ~1,35 ед.): обтекаемый пергаментный корпус, графитовое
  «лицо» с визором, глазами-диодами и куполом-сенсором, полоса со светящейся линией на спине, моторы бёдер со светящимися
  кольцами, пергаментные бёдра, графитовые изогнутые голени, резиновые лапы. Ноги — обратная кинематика (колени назад):
  ступни стоят на земле, не скользят. План: `stays` — куда идти (рысь, скорость `speed`), `actions`: `hop` (прыжок
  0,75 с), `stand` (на задних лапах, передние перед собой машут по очереди, `dur` 2,5 с), `dance` (`dur` 4 с: пружинит
  в такт, качается, поднимает передние лапы, посередине встаёт на задние и машет, в конце — прыжок с оборотом).
- `AuraHand.tsx` — **роборука** (`HandModel`, правая кисть ~1 ед. от запястья до кончика среднего): графитовые глянцевые
  фаланги с пергаментными накладками, шарниры со светящимися лимонными кольцами, ладонь сужается к запястью, пергаментное
  предплечье. Позы `POSES`: `open`, `relaxed`, `fist`, `point`, `pinchOpen`, `pinch` (подобран численно — кончики большого
  и указательного сходятся в точку), `hold` (держит предмет ~0,1 ед.). План `keys`: `{at, pose, p, rot}` (rot — [наклон,
  разворот вокруг вертикали, крен], порядок YXZ), `wiggle: [[от, до]]` — пальцы шевелятся волной, `items` — кубик/шарик:
  `start`, `size`, `carry` — когда зажат щипком (точка щипка `pinchPoint` считается по позе). Чтобы взять предмет:
  `p: handReach(точка предмета, rot)` — щипок придёт ровно в предмет. Подставка — `HandStand`.
**Витрина** — композиция `Aura3DShowcase` (`src/compositions/Aura3DShowcase.tsx`, ~37,5 с): AGV привозит коробки,
разворачивается, поднимает площадку, принимает и выгружает коробку, уезжает; манипулятор двигается в разных плоскостях,
переносит коробку со стола на стол; робособака идёт, встаёт на задние лапы, танцует; роборука машет пальцами, берёт кубик
щипком и переносит по дуге. Готовый рендер — `finished-videos/3d-арсенал/aura-3d-витрина.mp4` (+ раскадровка рядом).
Как вставить в ролик: `<Stage cam={…} left top width height>` поверх кадра (фон прозрачный) и внутри модели с планами,
времена — секунды от начала `Sequence`; несколько моделей в одной сцене видят друг друга (общий свет, тени, камера).

**Вступление** (решение пользователя 12.10.2026, ~3 с): первый кадр — большой робот (масштаб 4) по центру машет, слева у его

  Спектральный `afftdn` больше не используем — от него голос звучал «как из трубы».

  предела «выедал» верх согласных и хвосты слов (−3,5 дБ на 8–16 кГц), а компрессор с подъёмом +3 дБ поднимал хвосты слов —
  отражения улицы — на 3,2 дБ (это и было эхо), эквалайзер давал «телефонную» середину. Теперь: шумодав давит не глубже
  18 дБ (`denoise.py --limit`, `DFN_LIMIT` в `cut_pauses.py`; кэш `clean.wav` со старыми настройками пересчитывается сам),
  цепочка `AUDIO_CHAIN` — срез < 70 Гц, −1 дБ 300 Гц, +3 дБ от 5 кГц, де-эссер, компрессор −14 дБ 1,8:1 без подъёма.
  Итог: хвосты слов как в исходнике, тембр речи ±1 дБ от исходника. Шумодав окна Монтажной (RNNoise) настроен так же.
- **HDR iPhone → естественный цвет** (жалоба пользователя 15.10.2026: «я какого-то бледного цвета в кадре, сделай с естественным
  цветом»): исходники iPhone в HDR (HLG / Dolby Vision, bt2020) раньше уходили в склейку 8-битными с пометкой HDR, и в рендере
  спикер выходил бледным и холодным. Теперь `npm run cut` сам переводит такой исходник в bt709: тональная кривая hable
  (`zscale` → `tonemap`) + тёплая коррекция (насыщенность 1,25, контраст 1,08, тёплые полутона), обычный (SDR) — без изменений
  (`HDR_TO_SDR` в `scripts/cut_pauses.py`). Уже нарезанные склейки — `python3 scripts/hdr_grade.py <…>.cut.mp4 …` (кадры и звук
  те же, прежний файл — `<клип>.cut.hlg.mp4`); после — пересчитать вырезку спикера (`npm run matte`), если она нужна.
- **Паузы — по звуку после шумодава, «эканья» и цыканья** (решение пользователя 14.10.2026: «обработай звук, убери помехи и
  сделай шумодав, убери паузы и ненужные слова, эканья и цыканья»; ролики сняты на улице — шум города прятал паузы от
  `silencedetect` по сырому звуку): `npm run cut` сначала чистит всю запись DeepFilterNet (кэш `_work/<клип>.clean.wav`),
  потом ищет паузы по чистому звуку кадрами по 10 мс (порог — на 30 дБ тише громкой речи); всплески до 60 мс внутри паузы
  (цыканья, щелчки языком, вдохи) паузу не прерывают — вырезаются вместе с ней. Кусок звука между паузами короче 1,2 с без
  единого слова Whisper распознаётся отдельно: «э», «эм», «мм», «а-а» или пустота — вырезается («эканье»), иначе остаётся
  (в лог — «без слов, но слышно …»). Оговорки и повторы («я, я буду») Whisper часто не пишет — их по-прежнему ищу глазами
  в тексте и режу `--drop`. По-старому: `--vad raw`; без поиска «эканий»: `--no-fillers`.
- **Пересборка готового ролика**: `python3 scripts/rebuild.py <props-имя> <клип> [--cut 48.1-49.9,68.1-69.3]` —
  точная склейка + новый звук + вырезки (секунды **готового** ролика, как называет пользователь); старая склейка и props
  сохраняются в `_work/<клип>.cut.v1.json` / `.props.v1.json`, всё переносится на новую шкалу (`scripts/retime.py`:
  слова, плашки, логотипы, перебивки, зумы, финал). Перед вырезкой распознай кусок заново (whisper `-ml 1`) — оговорки
  и повторы («у нас, у меня, у нас…») видны только так. После — пересчитать вырезку спикера (`npm run matte`).
- **Длина ролика** «должен заканчиваться на 1:45» → `ctaSeconds = 105 − speechSeconds` (может быть отрицательной —
  тогда ролик обрезается сразу после последней фразы).
- **Музыка по умолчанию — `inspiring-corporate-soundrider`** (как в «Авто»), во всех роликах и темах пайплайна
  (решение пользователя); громкость 0.078, финал 0.18; если просит тише — 0.055 / 0.13.
- **Размер логотипов**: `logos[].scale` (вся группа) или `items[].scale` (один логотип) — 1.5, 2; карточки растут,
  слоты остаются вне зоны лица.
- **Перебивка «карточкой в углу»**: `broll[].mode: "pip"` — картинка на весь экран, спикер уезжает карточкой в правый
  нижний угол (x 690–1020, y 1060–1500, выше интерфейса Instagram) на 1–2 с, субтитры сдвигаются влево. Вырезка спикера не нужна.
- **Перебивка «экраном»** (решение пользователя 08.10.2026, приём из финала в других местах): `broll[].mode: "screen"` —
  картинка на весь кадр, спикер уменьшается в большой «экран» по центру (x 165–915, y 270–1230, рамка 14 px: белая у GTT,
  графитовая у Aura, лёгкий 3D-наклон) и возвращается. Чередовать с вырезкой (`cutout`) и углом (`pip`); вырезка спикера не нужна.
- **Флаги**: `flags: [{at, until, items: [картинки]}]` — небольшие развевающиеся флаги полукругом над головой от плеча
  до плеча, выскакивают по очереди (`src/components/Flags.tsx`, картинки `интернет-материалы/флаги/`);
  `bgFlags: [{at, until, src}]` — большой 3D-флаг на ветру за спиной (ткань с волнами, складками и светом), спикер вырезан
  и стоит перед ним (отрезок — в `--ranges` для matte). Пример: «Интро» — страны Азии на «опыт в Юго-Восточной Азии»,
  флаг Китая на «живу в Китае».
- **Второй ракурс**: если пользователь прислал запись второй камеры (`<клип>-2.*` рядом с исходником), пайплайн режет её
  по тем же кускам (`scripts/angle_b.py`, сдвиг по звуку находится сам) и иногда переключает кадр на боковой план
  (`angleB.shots`, ~раз в 10 с, по 2–3,5 с, не на перебивках, городах, чек-листах и финале).
- **Видео внизу экрана** (`clips: [{at, until, src, from, kicker, title}]`, решение пользователя для роликов про роботов):
  спикер поднимается (как с городами), снизу панель с видео работы робота (`ClipPanel`) — свои ролики пользователя
  с сайта aura-robotics.ru лежат в `source-videos/aura-robotics/видео-с-сайта/`.
- **Короткие куски склейки** (< 0,7 с) больше не меняют уровень зума — раньше они «мелькали» и выглядели как ускорение
  (жалоба на «Кондитерку»).

# Склейка из нескольких роликов: говорящая голова + перебивки (решение пользователя 25.10.2026)

Пользователь прислал 13 роликов и 5 фото с завода SANY: «собрать ролик с эффектами… плавные наезды камеры и отдаления,
переходы между роликами креативно обыгрывать, субтитры накладывай только там, где я выступаю как говорящая голова…

1. `npm run transcribe` на все ролики — по тексту видно, где человек говорит (у роликов без речи Whisper пишет мусор вроде
   «Субтитры делал …» — это тишина или чужая речь, такие ролики — перебивки); `--lang auto` показывает чужой язык (гид).
2. `npm run cut` только на роликах с речью (чистый голос, паузы), `npm run grid` — линия глаз (`focus`, `faceTop`).
3. Кадры перебивок каждые 2 с (обзорный лист) → лучшие 1,6–2,6 с; план кусков `монтаж.json`: речь по смысловым
   блокам, между ними перебивки по 2 куска (≈4 с), в конце — кадр для финала.
4. `npm run assemble -- ../source-videos/<папка>/монтаж.json` → `_work/<name>.joined.mp4` (+ слова только речи,
   границы кусков). Звук перебивок тихий (`broll_volume` 0.28), музыка с `duck` громче на перебивках.
5. Props TalkReelPro на склейку: `fx` на каждом стыке — каждый раз другой (`whip`, `leak` тёплый/холодный, `defocus`,
   `wipe` из угла, `bw` ч/б → цвет при возврате к спикеру); `zooms` на каждом куске (на перебивках `push` вперёд по
   движению и `pull` с открытием плана, на речи `push`, на ударных словах `punch`); `cuts` — только джамп-каты внутри речи;
   фото пользователя — `panels` с разных сторон с подписью; заголовок `titles` за спикером в начале (вырезка `npm run
   matte` только на этот отрезок); `checklists` + `captionsAt` none; финал `site` на последней перебивке со спикером.
6. Пробные кадры — `remotion still … --frame=44+сек×30` (44 кадра — заставка GTT), потом полный рендер.
Логотипы спецтехники — `source-videos/логотипы/спецтехника/` (SANY, XCMG из SINOTECH); логотипа нет (Zoomlion) —
нейтральная текстовая карточка в папке ролика, без подделки фирменного знака.
HDR iPhone: `hdr_filter` берёт первое поле ответа ffprobe — у роликов с поворотом он печатает `arib-std-b67,`, и до
25.10.2026 перевод HDR → SDR в `npm run cut` и в движке Монтажной молча пропускался (ролики уходили в рендер бледными).

# Монтажная (montazh/) и поля для неё (22.10.2026)

Приложение `montazh/` (описание — `montazh/README.md`) играет `TalkReelPro` в Remotion Player прямо на видео
пользователя. Для этого в шаблоне:
- `grade` — цветокоррекция кадра спикера и перебивок, CSS filter (`brightness(…) contrast(…) saturate(…) sepia(…)`),
  пресеты — `montazh/app/grades.ts`; складывается с ч/б из `fx`;
- `audioSrc` — отдельный звук вместо звука `mediaSrc` (в Монтажной — «чистый голос» для предпросмотра);
- `cutoutSrc: ""` — вырезки ещё нет: слои вырезки не рисуются, перебивка «вырезкой» показывается карточкой в углу
  (`pip`), хуки и графики — поверх спикера. В рендере задания движок сначала считает вырезку (`npm run matte`);
- `edl: [{src, from, to, audio?}]` — **монтажный лист** (шаг «Склейка», решение пользователя 22.10.2026: несколько
  роликов, лучшие дубли, чистка пауз, эканий, мусорных слов и цыканий): ролик играется кусками разных файлов встык
  (`src/components/EdlVideo.tsx`: везде, где показывается спикер — кадр, карточка в углу, финал, размытый фон, —
  `SpeakerVideo` вместо `OffthreadVideo` по `mediaSrc`; звук — `EdlAudio`, у куска свой чистый голос `audio`).
  Только для предпросмотра: движок склеивает лист заранее (`montazh/engine/edl.py`) и рендерит без `edl`.
  Новый слой с видео спикера — тоже через `SpeakerVideo`, иначе в Монтажной он будет пустым.
Эффекты библиотеки — `montazh/app/effects.ts` (каждый — приём этого шаблона); новый приём шаблона, которым удобно
пользоваться по секундам, добавляй туда же с превью (`node montazh/scripts/render_previews.mjs --only <id>`) и в
разбор команд словами (`montazh/app/commands.ts`, пример — в `EXAMPLES`).

Приёмы Монтажной в шаблоне (решения пользователя 22.10.2026, код — `src/components/Emojis.tsx`, `src/components/MontazhFx.tsx`):
- `zooms[].kind: "pull"` — **отдаление**: кадр сразу крупно (+amount) и плавно отъезжает к общему плану за `hold`, со звуком «вжух»;
- `emojis: [{at, until, src, x, y, size, anim}]` — **живые эмодзи** Google Noto (`интернет-материалы/эмодзи/<название>.webp`,
  CC BY 4.0 — автор в описании публикации): `pop` выскакивает и покачивается, `float` всплывает и тает, `shake` трясётся,
  `burst` — россыпь из 6; по умолчанию справа над головой (x 800, y 470), не на лицо; щелчок на появлении;
- `speaker: [{at, until, corner, scale, style, bg, image, tilt}]` — **спикер уменьшается** в угол (`tl/tr/bl/br/top/bottom/left/right/center`),
  `style`: `frame` — кадр в рамке бренда, `round` — лицо в круге, `contour` — вырезка по контуру с обводкой (нужен `cutoutSrc`,
  без него — рамка); фон: `blur` (размытый кадр), `brand`, `dark`, `image`; въезд и возврат 0,5 с со «вжухом»;
- `panels: [{at, until, src, from, size, title, push, fit, h}]` — **выдвижной экран** с видео или фото: `top`, `bottom`, `left`, `right`
  или из угла `tl/tr/bl/br` (с поворотом и пружиной); спикер отодвигается от экрана (`push: false` — стоит); `h` — высота
  экрана сбоку (по умолчанию 1100 px, низ на y=1520): при `captionTop` ниже 1500 ставь `h` так, чтобы подпись не легла на субтитры;
- `texts: [{at, until, text, x, y, size, rx, ry, rz, color, color2, font, plane, anim, depth}]` — **текст в 3D**: положение, размер,
  повороты по трём осям, шрифт (`grotesk` Oswald, `display` Unbounded, `serif` Playfair курсив, `hand` Caveat, `mono`, `body`),
  объём букв `depth` цветом `color2`, `plane: behind` — за спикером (нужен `cutoutSrc`, как у хуков), `front` — перед;
  появление `rise / fly / swing / type / fade`;
- `lists: [{at, until, style, title, items}]` — **перечисления в разных подачах**: `flip` (флипчарт на мольберте, пункты
  маркером, квадратики отмечаются) и `typewriter` (тёмная панель, печать по буквам) поднимают спикера, как планшет;
  `cards` (карточки стопкой с переворотом), `stickers` (липучки по бокам от головы), `numbers` (огромная цифра + пункт,
  по одному), `bubbles` (пилюли дугой вокруг головы) — без подъёма; щелчок на каждом пункте. Планшет `checklists` остаётся;
- `palette: {text, accent, ink}` — цвета субтитров, акцента (текущее слово, выделения, цифры) и текста на акценте на весь ролик;
  `paletteAt: [{at, until, …}]` — смена цветов на отрезке. Готовые сочетания и проверка своих — `montazh/app/palettes.ts`.

# Рекламный ролик о приложении: AppPromo (решение пользователя 27.10.2026)

«Гайд видео о нашем приложении… по примеру рекламного ролика… звук, текст и визуал должны совпадать и чётко
синхронизироваться… продать в дальнейшем компаниям». Ролик собирается из настоящих экранов приложения GTT (веб-сборка
`Ostap-87/GTT-APP`, `mobile/dist`) под голос диктора; всё время берётся из слов голоса.

Порядок (пример — `promo/2026-10-27-gtt-app.*`):
1. **Сценарий** `promo/<дата-тема>.json`: `beats[]` — сцена = одна фраза диктора (`say`), заголовок `title` (акцент `**так**`),
   кикер `kicker`, плашки `chips[{text, on}]`, крупные слова `words[]`, `cues[{clip, mark, on, focus?, launch?}]` — какой клип
   экрана и какая метка в нём должны совпасть со словом `on`; особые сцены `visual`: `chaos`, `reveal` (главный экран с иконкой),
   `montage`, `wechat`, `three`, `counter`, `final`. Человеческий вид сценария — `promo/<дата-тема>.md` (таблица для пользователя).
2. **Голос** — `python3 scripts/promo_voice.py promo/<…>.json --piper <модель.onnx>` (черновик, бесплатно, Piper ru_RU-dmitri) или
   `--audio <готовая озвучка>` (один файл: Higgsfield / диктор — режется на сцены по словам Whisper). Пишет
   `source-videos/<name>/voice/voice.wav` и `timing.json` (время каждого слова). ElevenLabs напрямую в рекламу не идёт
   (бесплатный тариф — только некоммерческое); финальный голос — Higgsfield `elevenlabs_v4` (тариф пользователя Starter, ≈ 9
   кредитов за 2,5 тыс. знаков) только с согласия пользователя, или живой диктор.
3. **Экраны** — `node scripts/app_record.mjs promo/<…>.clips.mjs --base http://localhost:8790` (веб-сборку приложения отдаёт
   `npx serve -s dist -l 8790` в `GTT-APP/mobile`; «Еда рядом» — локальный сервер приложения в демо-режиме, сборка с
   `EXPO_PUBLIC_NEARBY_URL=http://localhost:8787`). Клип: путь, демо-данные `seed` (localStorage `gtt:v1:*`, только вымышленные
   люди, визитки, чеки) и действия `ui.tap / ui.scroll / ui.type / ui.mark`. Ретина — флагом `--force-device-scale-factor=2`
   (с `deviceScaleFactor` контекста screencast отдаёт кадры вдвое меньше). Стартовый 3D-экран приложения в облаке рисуется 2 к/с —
   вместо него в ролике иконка на главном экране (`reveal` + `launch`), а для сцены «9 стран» — стоп-кадр.
4. **Сведение** — `python3 scripts/promo_build.py promo/<…>.json`: клипы подгоняются под голос (между действиями лишнее
   срезается, нехватка — стоп-кадром), каждое нажатие стоит на своём слове (минус 0,45 с на подлёт пальца). Пишет
   `source-videos/<name>/screens/<сцена>.mp4` и `props/<name>.json`.
5. **Рендер** — композиция `AppPromo`: `npx remotion render src/index.ts AppPromo ../finished-videos/<name>.mp4 --props=./props/<name>.json`
   (9:16); 16:9 — те же props с `"format": "h"` → `<name>-16x9.mp4`. Внутри: телефон (один на весь ролик, поворачивается к новой
   сцене), экран следующей сцены заезжает справа, палец и круг на каждом нажатии + щелчок, наезд на элемент (`focus`),
   заголовки и плашки на словах, субтитры по 3 слова (`showCaptions`), музыка тише голоса, заставка GTT (в 16:9 — масштаб по ширине).

**Версия 2** (решение пользователя 27.10.2026: «ещё более креативно… максимальное удобство для групп… удобно для координаторов

`promo/2026-10-27-gtt-app-v2.*`. Сценарий может жить в папке другого ролика: `sourceDir` (папка `source-videos/`, общие клипы),
`voiceDir` (`voice-v2`), `screensDir` (`screens-v2`). Новые сцены `visual`:
- `chats` — уведомления групповых чатов Telegram / WeChat / WhatsApp сыплются и копятся (значки — простые свои глифы в цветах

- cue `flip: true` (обычно с `lead: 0`) — **переворот телефона** по вертикальной оси на этом слове: старый экран уходит до 90°,
  новый приходит с −90° (делегат → координатор);
- `orbit: [{text, icon, on}]` — значки инструментов (`cal`, `pin`, `star`, `bag`, `table`, `users`, `chat`) выскакивают на своих

- `receipts` + `report: {on, excelOn, pdfOn, rubOn, doneOn}` — три чека (`img/chek-*.jpg`, вымышленные) вылетают из телефона и

- `mindgrow` + `mind: {reportOn, mapOn, companiesOn, dealsOn, contactsOn, nextOn, autoOn}` — стопка «Итоги поездки.pdf», затем
  майндмэп растёт сам (ветки-компании в два столбца, листья-договорённости, контакты, следующие шаги), на «автоматически» светится;
- `threeOrder` — порядок трёх экранов в сцене `three`.
**Голос клиентом**: Higgsfield `generate_audio` с `seed_audio` и `medias: [{role: "audio_references", value: <media_id образца>}]` —
голос повторяет тембр образца в каждой генерации (≈ 0,7 кредита за короткую фразу; свой голос через `create_voice` на тарифе
Starter упёрся в лимит голосов). Образец — 2–3 минуты чистой речи человека (`voice/clone/ostap-sample.mp3`), генерировать по сценам
по 2–3 за раз (больше — ошибка 429), сцены — `voice-v2/beats/<id>.wav`, затем `promo_voice.py --beats-dir`. Только с согласия
человека, чей голос, и с показом цены.

Звуки заставки GTT лежат в `source-videos/2026-10-07-byt-tehnika/sfx/` — их не заменять указателями LFS при чистке диска
(без них рендер любого ролика GTT падает на `whoosh.wav`).
