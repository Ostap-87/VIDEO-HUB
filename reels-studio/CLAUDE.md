# Роль

Ты делаешь ролики Instagram Reels для GlobalTechTour (globaltechtour.ru) на Remotion
в этом проекте. Все ролики должны выглядеть как один канал. Ядро стиля менять нельзя:
любое решение сверяй с этим документом.

# Бренд и аудитория

- Бренд: GlobalTechTour. По текущим материалам: экспедиции на производства и в технокомпании Китая. Если тема шире, уточни у меня.
- Аудитория: широкая, кому интересны технологии. Пиши без жаргона, термин объясняй одной фразой.
- Язык: русский.
- Тон — сочетание четырёх: хук интригующий (конкретный факт или противоречие), подача живая и разговорная, факты с цифрами и разбором, всё по делу и без хайпа.

# Формат

- 1080×1920, 30 fps, длина 30–60 секунд.
- Безопасная зона Instagram: сверху 250 px, снизу 380 px, по бокам 64 px. Текст не заходит под интерфейс. Проверяй через `showSafeZone`.
- Структура: хук 0–3 с, основная часть, финал последние ~3 с (заголовок + синяя плашка CTA).
- Финальный CTA всегда ведёт на сайт globaltechtour.ru. Текст плашки по умолчанию: «Подробности на сайте».

# Ядро стиля («светлый framed», закреплён 21.09.2026). Не менять

Цвета (только из `src/theme.ts`):
primary #EEEEF2 фон сцены, accent #2563EB акценты и плашка CTA, text #17171D основной текст,
muted #6B6B76 подписи, surface #FFFFFF плашки, line #D5D5DD рамки.

Шрифты (`src/fonts.ts`):
- Заголовки: Unbounded 700.
- Основной текст: Inter 400, акцент Inter 700.
- Кикер, плашка сайта, счётчик: моноширинный (JetBrains Mono 500, в гайде шрифт не назван).

Кадр:
- Фото или видео всегда в карточке: отступы 48 / 200 / 48 / 200, скругление 64, рамка 2 px line, мягкая тень.
- Не заливать фото тёмным градиентом.
- Внизу карточки светлая дымка (blur 30 px, полупрозрачная, ~64% высоты) под текстом.
- Плашка сайта слева-сверху: `tone: light` на светлом кадре, `dark` на тёмном или ярком.
- Счётчик «1 / 3» справа-сверху в сериях и каруселях.
- Другой брендинг (логотип, водяной знак) не добавлять. Только плашка сайта.

Типографика:
- Кикер: моно 30 px, капс, трекинг 0.14em, accent.
- Заголовок: Unbounded 700, 96 px, межстрочный 1.04.
- Подзаголовок: Inter 400, 44 px, muted.
- Основной текст: Inter 400, 56 px, межстрочный 1.36.
- Акцент: слова в `**двойных звёздочках**` красятся в accent. Один акцент на экран.

# Субтитры (говорит человек в кадре)

Три режима, чередуются по смыслу:
1. По 3 слова, текущее слово accent (Unbounded 700, 72 px). Режим по умолчанию для обычной речи.
2. Фразой целиком (Inter 400, 56 px, акцентные слова Inter 700 синим). Для объяснений и длинных мыслей, смена по смыслу.
3. Одно слово крупно (Unbounded 700, ~140 px, с «попом»). Для цифры или ключевой мысли.

Правила чередования:
- В одной сцене один режим. Режим меняется не чаще, чем раз в ~4 секунды.
- Режим 3 — не чаще одного раза за 8–10 секунд.
- Субтитры не перекрывают плашки списка и не заходят ниже безопасной зоны.

# Анимация и эффекты

Динамика средняя: плавно + акцентный «поп» на цифрах и ключевых словах.

- Базовое появление: слова по очереди, снизу вверх на 40 px, пружина snappy (damping 18, stiffness 180, mass 0.8), шаг 2–3 кадра.
- «Поп»: пружина с лёгким перелётом (масштаб 0.8 → 1.08 → 1). Только на accent-словах и цифрах, не чаще одного раза в ~3 секунды.
- Смена слайдов в TextReel: новый слайд наезжает справа за 14 кадров.
- Фото: медленный наезд 1.0 → 1.08 за длину сцены. Видео не масштабируем.
- Финал: плашка CTA выезжает снизу справа.
- Стоп-листа эффектов нет: тряска, глитч, свечение, резкие зумы, эмодзи, стикеры разрешены.
  Правило дозировки (предложение, можно снять): ядро стиля неизменно, а акцентные эффекты используются редко,
  не больше одного на сцену и только если усиливают смысл. Эффект на фоне нарушенного ядра (другой шрифт, цвет, рамка) недопустим.

# Цифры и факты (миксуем три приёма)

1. Цифра внутри фразы синим акцентом (по умолчанию для всех цифр).
2. Крупная цифра на весь кадр: Unbounded 700 ~220 px, с «попом», под ней подпись muted.
3. Счётчик: число набегает от нуля за ~1.2 с с замедлением к концу.
Главный факт ролика — приём 2 или 3, один на ролик. Остальные цифры — приём 1.

# Шаблоны

1. **Разбор / рассказ**: человек в кадре, обложка 3 с, субтитры (3 режима), финал.
2. **Список «топ-3 / топ-5»**: видео идёт, пункты всплывают плашками поверх.
   Плашка: белая полупрозрачная с blur, как плашка сайта; номер Unbounded 700 синим, подпись Inter.
   Плашка появляется, когда о пункте начинают говорить, уходит через ~4 с, одновременно не больше двух.
3. **Репортаж с производства**: видео с титрами: кикер с локацией и названием, короткие подписи Inter, цифры по правилам выше.
4. **Факт или цитата одной фразой**: cover-слайд: кикер, заголовок Unbounded с акцентом, подзаголовок, финал с CTA.

Новые шаблоны собираются только из существующих компонентов (Frame, Hook, Captions, Cta, RichWords, Media).

# Материалы и звук

- Фото и видео: любые, главное по теме. Если кадр тёмный или пёстрый, ставь `tone: dark` на плашке сайта.
- Звук: человек говорит в кадре + музыка. Музыку подбирай под каждый ролик, тише голоса (около 15–20% громкости, можно поправить). Только треки с лицензией для коммерческого использования, источник уточняй у меня.

# Правила работы

1. Перед сборкой запроси недостающее: тему, сырьё (видео, фото), хронометраж, ключевой факт, данные.
2. Если для ролика не хватает данных, спрашивай меня. Ничего не выдумывай: ни факты, ни цифры, ни названия компаний.
3. Не меняй `src/theme.ts` и `src/fonts.ts` без прямого указания.
4. Каждый ролик оформляй как props-файл `props/имя.json` для композиции Reel или TextReel.
5. Проверяй безопасную зону и читаемость текста на дымке.
6. Рендери и показывай результат: `npx remotion render src/index.ts Reel ../finished-videos/имя.mp4 --props=./props/имя.json`.
7. Папки: сырьё бери из `source-videos/` (это public-папка Remotion, в `mediaSrc` путь внутри неё), готовые ролики и обложки сохраняй в `finished-videos/`. Видео и аудио идут через Git LFS.
8. Показывай процесс скриншотами: после каждого рендера или правки нарезай раскадровку
   `npm run frames -- ../finished-videos/имя.mp4` (кадр каждую секунду; `--every 2`, `--at 0.5,3,7`)
   и сразу показывай её мне в чате. Исходник от меня тоже сначала режь на кадры и показывай, что в нём видно.
9. Всё сохраняй в репозиторий `Ostap-87/VIDEO-HUB`, ветка `main`: коммить и пушь после каждого исходника, готового ролика или правки.
10. Новая возможность = обновлённые правила в том же коммите: этот файл (как пользоваться + «Статус реализации»), README и при необходимости корневой `CLAUDE.md`.
