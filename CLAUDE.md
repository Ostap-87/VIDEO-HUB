# VIDEO-HUB: правила работы с репозиторием

Это общие правила для любой сессии Claude в этом репозитории. Правила самих роликов
(стиль, шаблоны, субтитры) лежат в `reels-studio/CLAUDE.md`.

## Куда что сохранять (обязательно)

- **Сырые исходники**, которые присылает пользователь (видео, фото, музыка, скриншоты-референсы),
  сразу сохраняй в `source-videos/`. Если исходников по ролику несколько, клади их в подпапку
  с понятным именем, например `source-videos/2026-10-07-zavod-shenzhen/`.
- **Готовые ролики и обложки** сохраняй в `finished-videos/`. Имя файла совпадает с props-файлом:
  `reels-studio/props/имя.json` → `finished-videos/имя.mp4`.
- Черновые рендеры (`finished-videos/_*`) и раскадровки (`finished-videos/frames/`) в git не идут.
- Видео и аудио хранятся через Git LFS (`.gitattributes`). Новые форматы медиа добавляй туда же.

## Куда отправлять

- Все изменения коммить и пушь в ветку `main` репозитория `Ostap-87/VIDEO-HUB`.
  Не оставляй работу в служебных ветках `claude/...`: пользователь работает с `main`.
- Пушь после каждого сохранённого исходника, готового ролика или правки правил.

## Правила обновляются вместе с навыками (обязательно)

Каждый раз, когда появляется новая возможность (шаблон, эффект, режим субтитров, скрипт,
приём монтажа, договорённость с пользователем), в том же коммите обнови правила:

- `reels-studio/CLAUDE.md`: опиши, как и когда использовать новое, и обнови раздел «Статус реализации».
- `reels-studio/README.md`: команды и инструкции для человека.
- Этот файл: если поменялись папки, порядок работы или договорённости по репозиторию.

Правила без описания новой возможности считаются незаконченной работой.

## Скиллы Remotion

В `.claude/skills/` лежат официальные скиллы Remotion (https://github.com/remotion-dev/skills),
они подхватываются в каждой сессии. Перед работой с кодом роликов загружай нужный:

- `remotion-best-practices` — общий вход, если не ясно, какой нужен;
- `remotion-markup` — анимации, тайминги, переходы, эффекты;
- `remotion-captions` — расшифровка речи и субтитры;
- `remotion-multimedia` — видео, аудио, метаданные файлов;
- `remotion-render` / `remotion-studio` — рендер и превью;
- `remotion-create`, `remotion-docs`, `remotion-upgrade`, `remotion-maps`, `remotion-interactivity`, `remotion-saas` — по задаче.

## Скиллы ElevenLabs (голос, звук, музыка)

- `text-to-speech` — закадровый голос; `speech-to-text` — расшифровка речи с таймингами слов для субтитров;
- `music` — фоновая музыка под ролик; `sound-effects` — звуковые эффекты (вжух, щелчки, удары);
- `voice-isolator` — очистить голос от шума цеха; `voice-changer`, `dubbing` — смена голоса и перевод озвучки;
- `setup-api-key` — проверка ключа.

Ключ ElevenLabs в облаке хранится как сетевой секрет среды (хост `api.elevenlabs.io`, заголовок `xi-api-key`),
а не в `.env` и не в чате. Никогда не проси вставить ключ в переписку и не коммить его.
Сгенерированный звук сохраняй в `source-videos/` (голос — `voice/`, музыка — `music/`, эффекты — `sfx/` внутри папки ролика).
Музыка ElevenLabs допустима для коммерческого использования только на платном тарифе; тариф уточняй у пользователя.

Правила бренда из `reels-studio/CLAUDE.md` важнее общих советов скиллов.
Откуда скиллы и как их обновить: `.claude/skills/SOURCE.md`.

## Показывать процесс

Пользователь хочет видеть работу скриншотами: исходник сначала нарезается на кадры
(`npm run frames` в `reels-studio`), после каждого рендера или правки раскадровка показывается в чате.
