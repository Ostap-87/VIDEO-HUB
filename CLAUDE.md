# VIDEO-HUB: правила работы с репозиторием

Это общие правила для любой сессии Claude в этом репозитории. Правила самих роликов
(стиль, шаблоны, субтитры) лежат в `reels-studio/CLAUDE.md`.

## Куда что сохранять (обязательно)

- **Сырые исходники**, которые присылает пользователь (видео, фото, музыка, скриншоты-референсы),
  сразу сохраняй в `source-videos/`. Если исходников по ролику несколько, клади их в подпапку
  с понятным именем, например `source-videos/2026-10-07-zavod-shenzhen/`.
- **Готовые ролики и обложки** сохраняй в `finished-videos/`. Имя файла совпадает с props-файлом:
  `reels-studio/props/имя.json` → `finished-videos/имя.mp4` (полное качество, Reels) и `имя-stories-N.mp4` (части Stories).
  Лёгкие копии до 30 МБ (те, что отправляю в чат для скачивания) тоже сохраняй: `finished-videos/для-телефона/имя.mp4`.
- **Всё, что скачано из интернета** (фото городов, картинки, логотипы со сторонних сайтов), сохраняй в
  `интернет-материалы/тема/` (например `интернет-материалы/города/`), автора, лицензию и ссылку пиши в
  `интернет-материалы/АВТОРЫ.md`. Только лицензии с коммерческим использованием (CC0, CC BY, CC BY-SA).
  Варианты на выбор — в подпапку `варианты/`; перед финальным рендером показывай пользователю лист сравнения.
- Public-папка Remotion — корень репозитория, поэтому пути в props пишутся от корня: `source-videos/...`, `интернет-материалы/...`.
- Черновые рендеры (`finished-videos/_*`) и черновые раскадровки (`finished-videos/frames/`) в git не идут.
  Раскадровка **финального** ролика сохраняется в репозиторий: `finished-videos/раскадровки/имя.jpg` (решение пользователя).
- Музыка из интернета — `интернет-материалы/музыка/` (только CC0 / CC BY, автор в `АВТОРЫ.md`); треки небольшие и хранятся в обычном git, не в LFS (`.gitattributes`).
- Видео и аудио хранятся через Git LFS (`.gitattributes`). Новые форматы медиа добавляй туда же.
- **Место на диске** в облаке ограничено (~250 ГБ на всех, свободно обычно 1–2 ГБ). Chrome рендера Remotion отказывается
  работать, когда места мало («disk space is low», «Page crashed»). Главный запас — кэш Git LFS (`.git/lfs`, копия каждого
  ролика): после пуша его можно чистить `git lfs prune --force` (удаляет только уже отправленные на GitHub объекты, файлы
  в папках остаются) — освобождает несколько ГБ. Ещё: целый `<имя>-stories.mp4` после нарезки на части, старые
  `_work/*.alpha.webm` готовых роликов (пересчитываются `npm run matte`).

## Презентации

Папка `презентации/`:
- `примеры/` — присланные пользователем примеры презентаций (сохраняй туда сразу, как и видео-сырьё);
- `шаблон/` — фирменный шаблон `.pptx`;
- `готовые/` — собранные презентации, имя `ГГГГ-ММ-ДД-тема.pptx`.
Процесс показывай так же: каждый слайд картинкой-превью в чате.

Шаблон готов (08.10.2026): `презентации/шаблон/` — HTML/CSS, повторяет дизайн примеров «ИИ» и «Alibaba» 1:1
(1920×1080 px = PDF 1440×810 pt, Sofia Sans (Extra) Condensed + Inter, синий `#1a73e8`). Содержание — JSON в
`презентации/контент/ГГГГ-ММ-ДД-тема.json`, сборка:
`python3 презентации/шаблон/build.py презентации/контент/ГГГГ-ММ-ДД-тема.json` → `готовые/ГГГГ-ММ-ДД-тема.pdf`,
`готовые/превью/<имя>/NN.png` и лист-обзор `готовые/превью/<имя>.jpg` (его и показывай в чате).
Презентация по туру с сайта собирается автоматически: `python3 презентации/шаблон/from_site.py <tour_id> --build`
(данные из бандла сайта, факты — дословно из описаний компаний, логотипы с `globaltechtour.ru/logos`, автоподгонка текста
`fit_check.mjs`); список всех 76 туров и что готово — `презентации/ЭКСПЕДИЦИИ.md`. Робот на фоне страны — поле `robot`.
Личные документы в стиле сайта ostapdotcenko.ru (не GTT): `презентации/ostapdotcenko/<дата-тема>/index.html` → `python3 презентации/ostapdotcenko/build.py <дата-тема>` (PDF A4 + превью), мини-интро на китайском `2026-10-12-intro-zh`, русском `2026-10-12-intro-ru` и английском `2026-10-12-intro-en` (маркер — сплошная плашка, не градиент: градиент с прозрачностью в некоторых просмотрщиках PDF чёрный); фото Остапа — `source-videos/фото-от-пользователя/остап/`.
Основная презентация компании — оригинал пользователя «Main GTT» (`примеры/Main GTT.pdf`) без слайда «Стоимость программ»: `готовые/2026-10-15-main-gtt-без-цен.pdf` (лёгкая копия для почты — `…-без-цен-лёгкая.pdf`). Пересборка в шаблоне (`контент/2026-10-15-gtt-основная.json`) пользователю не понравилась (15.10.2026): «давай возьмём за основу старую презентацию и просто уберём слайд с ценами»; подробности — `презентации/README.md`.
Типы слайдов: cover, why, layers, route, company, days, cases, benefits, market, conditions, steps, contacts, pitch-teams + pitch-plan (питч-дек на 2 страницы) —
формат JSON и команды в `презентации/README.md`. Факты — только с сайта globaltechtour.ru или от пользователя,
нет данных — явная заглушка `[уточнить …]`. Логотипы — из `source-videos/логотипы/` (карточки компаний на сайте
берут логотипы из `https://globaltechtour.ru/logos/<Имя>.png`).

## Присланный ролик — сразу в работу (решение пользователя 08.10.2026)

Получил ссылку или файл с роликом — сразу запускаю быстрый пайплайн `npm run auto` (порядок — в `reels-studio/CLAUDE.md`,
раздел «Быстрый пайплайн»), без предварительных вопросов. Инструменты ставятся сами при старте сессии
(хук `SessionStart` → `reels-studio/scripts/setup.sh`). Библиотеки пайплайна — `reels-studio/library/`; всё, чем
они пополнились при работе над роликом (бренд, фраза, заблокированная картинка), коммичу вместе с роликом.

## Логотипы компаний

Все логотипы роликов — библиотека `source-videos/логотипы/<отрасль>/` (`общие`, `ии`, `авто`, `бытовая-техника`, `чай-кофе`,
`кондитерка`, `косметика`, `ритейл`, `техгиганты`, `роботы`, `еда`, `медицина`, `финансы`, `логистика`, `авиация`, `недвижимость`, `энергетика`); каждый записан в `reels-studio/library/brands.json` с вариантами написания —

главнее найденных где-либо ещё. Нового бренда нет — ищи в репозитории `Ostap-87/SINOTECH`, папка `public/logos/` (~1000),
клади в библиотеку и дописывай `brands.json`.

фото к конкретному ролику (витрины, товары) — в папку ролика, например `source-videos/2026-10-07-konditerka/витрины/`.

## Монтажная — приложение для монтажа (решение пользователя 22.10.2026)

«Модуль, в который я добавляю сырое видео… субтитры в нашем стиле, переходы, шумодав, цветокоррекция — и в моменте
видеть, как это будет выглядеть… монтажный стол, писать на какой секунде что исправить… референсы в библиотеку,
где сразу видно эффект». Папка `montazh/` (решение: внутри VIDEO-HUB, Mac + браузер, ролики — файлом, через GitHub и
по ссылкам Google Диск / Яндекс Диск / файлообменники). Предпросмотр — настоящий `TalkReelPro` в Remotion Player.
Шаги: Исходник → Склейка (несколько роликов и фото, лучшие дубли, чистка пауз, эканий, мусорных слов и цыканий —
решение пользователя 22.10.2026; `montazh/app/assemble.ts`, движок — `montazh/engine/edl.py`) → Текст (Whisper в окне
или файл) → Звук (RNNoise A/B) → Цвет (пресеты = поле `grade`) → Монтаж
(эффекты из библиотеки по секундам + заметки) → Библиотека (превью 1–2 с) → Готово (задание `.job.json`).
Устройство и команды — `montazh/README.md`. Установка на Mac — ветка `montazh-dist` (Actions «Монтажная — сборка»):
`D=$(mktemp -d) && curl -fL https://codeload.github.com/Ostap-87/VIDEO-HUB/tar.gz/refs/heads/montazh-dist | tar -xzf - -C "$D" --strip-components=1 && bash "$D/install_mac.command"`.
Новый приём монтажа = эффект в `montazh/app/effects.ts` + превью (`node montazh/scripts/render_previews.mjs --only <id>`)
+ слова для строки команд (`montazh/app/commands.ts`).
Решения пользователя 22.10.2026 («писать в моменте, какие эффекты нужны… смайлы, хуки, приближение и отдаление по команде…
картинки на фоне по смыслу… скачивать готовое на компьютер… спикер в угол, в рамку или по контуру… экраны с разных сторон…
тексты в разных плоскостях… разные перечисления… цвета шрифта с рекомендуемой палитрой»): строка команд и голос (🎤),
картинки по смыслу (каталог Higgsfield, `montazh/library/images*`), эффекты «Спикер», «Экраны», «Текст в 3D», «Списки»,
«Цвета текста», кнопка **«Сделать ролик»**: сервер Mac кладёт файлы в релиз `montazh-<id>` и коммитит
`montazh/jobs/<id>.json` → GitHub Actions «Монтажная — рендер» (`montazh/engine/run_job.py`) → готовый ролик, копия для
телефона и раскадровка в том же релизе, окно показывает и скачивает. Ключ GitHub пользователь вводит в окне (fine-grained,
только VIDEO-HUB, Contents: Read and write), в чат — никогда. Рабочие файлы движка — `source-videos/montazh/` (вне git).
Задание с заметками («Монтажная, задание <id>») — props и заметки в `montazh/jobs/<id>.json`, файлы — релиз `montazh-<id>`;
заметки выполняю я, результат — в тот же релиз (или `finished-videos/`, если ролик идёт в публикацию).

## Скиллы Remotion

В `.claude/skills/` лежат официальные скиллы Remotion (https://github.com/remotion-dev/skills),
они подхватываются в каждой сессии. Перед работой с кодом роликов загружай нужный:

- `remotion-best-practices` — общий вход, если не ясно, какой нужен;
- `remotion-markup` — анимации, тайминги, переходы, эффекты;
- `remotion-captions` — расшифровка речи и субтитры;
- `remotion-multimedia` — видео, аудио, метаданные файлов;
- `remotion-render` / `remotion-studio` — рендер и превью;
- `remotion-create`, `remotion-docs`, `remotion-upgrade`, `remotion-maps`, `remotion-interactivity`, `remotion-saas` — по задаче.

## Скиллы ElevenLabs (голос, звук, музыка)

- `text-to-speech` — закадровый голос; `speech-to-text` — расшифровка речи с таймингами слов для субтитров;
- `music` — фоновая музыка под ролик; `sound-effects` — звуковые эффекты (вжух, щелчки, удары);
- `voice-isolator` — очистить голос от шума цеха; `voice-changer`, `dubbing` — смена голоса и перевод озвучки;
- `setup-api-key` — проверка ключа.

Ключ ElevenLabs в облаке хранится как сетевой секрет среды (хост `api.elevenlabs.io`, заголовок `xi-api-key`),
а не в `.env` и не в чате. Никогда не проси вставить ключ в переписку и не коммить его.
Сгенерированный звук сохраняй в `source-videos/` (голос — `voice/`, музыка — `music/`, эффекты — `sfx/` внутри папки ролика).
Тариф ElevenLabs: **бесплатный** (решение пользователя, 07.10.2026). Условия Free: ~10 000 кредитов в месяц
(около 10 минут озвучки), только некоммерческое использование и обязательное указание ElevenLabs.
Ролики GlobalTechTour — коммерческий контент, поэтому на бесплатном тарифе:
- в публикуемые ролики голос, музыку и эффекты ElevenLabs **не вставляем**; ElevenLabs — только для черновиков и проб;
- расшифровка речи для субтитров — бесплатно через Whisper (`@remotion/install-whisper-cpp`, модель с Hugging Face);
- звуковые эффекты — `@remotion/sfx` (без указания авторства); музыка — только треки с коммерческой лицензией от пользователя;
- кредиты экономь: перед генерацией говори пользователю, сколько символов уйдёт.
Если пользователь перейдёт на платный тариф (Starter и выше), обнови этот блок.

## Скиллы HyperFrames (HeyGen)

Второй движок: видео из HTML + CSS + GSAP, рендер через `npx hyperframes`. Вход — скилл `hyperframes`.
Полезные: `embedded-captions` (субтитры, в т.ч. «за спиной» человека), `talking-head-recut` (графика поверх говорящей головы),
`motion-graphics` (короткая инфографика, счётчики, карты), `hyperframes-animation`, `hyperframes-keyframes`,
`music-to-video` (монтаж в бит), `hyperframes-registry` (~400 готовых эффектов: глитч, зерно, переходы), `media-use`.

Какой движок брать (важнее того, что пишет сам скилл `hyperframes` про «движок по умолчанию»):
- Ролики GlobalTechTour по шаблонам `Reel` и `TextReel` — **Remotion** в `reels-studio/`. Это основной движок.
- **HyperFrames** — когда пользователь просит его прямо, для экспериментов и сложной моушн-графики,
  которую проще сверстать в HTML. Проекты HyperFrames клади в `hyperframes-studio/имя/`,
  готовый рендер — в `finished-videos/`, как обычно. Ядро стиля из `reels-studio/CLAUDE.md` обязательно и здесь.
- Не смешивай два движка в одном ролике без согласования с пользователем.
- Облачный рендер HeyGen и их платные API — только с согласия пользователя.

## Скиллы Hugging Face (модели ИИ)

Hugging Face — откуда берём открытые модели, которые работают прямо в облачной среде, бесплатно:
Whisper для расшифровки речи и таймингов субтитров, удаление фона, апскейл и т.п.
- `hf-cli` — скачать модель (`hf download ...`); `transformers-js` — запуск моделей из JS/Node (в т.ч. Whisper);
- `huggingface-best` — подобрать лучшую модель под задачу.
Модели не коммить в репозиторий: кэш лежит вне репозитория (`~/.cache/huggingface`).
Токен нужен только для закрытых моделей; хранить как сетевой секрет среды (хост `huggingface.co`,
заголовок `Authorization`, префикс `Bearer`), не в чате и не в файлах.
Что выбирать для расшифровки: бесплатно и локально — Whisper с Hugging Face; точнее и быстрее, но платно — ElevenLabs `speech-to-text`.

Правила бренда из `reels-studio/CLAUDE.md` важнее общих советов скиллов.
Откуда скиллы и как их обновить: `.claude/skills/SOURCE.md`.
